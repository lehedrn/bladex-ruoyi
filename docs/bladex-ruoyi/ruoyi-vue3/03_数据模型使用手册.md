## 2. 关联关系表

| 表名 | 字段 | 说明 |
|------|------|------|
| sys_user_role | user_id + role_id | 用户-角色多对多 |
| sys_role_menu | role_id + menu_id | 角色-菜单多对多 |
| sys_role_dept | role_id + dept_id | 角色-部门（数据权限用） |
| sys_user_post | user_id + post_id | 用户-岗位多对多 |

**注意：** 所有关联表无数据库外键约束，引用完整性由应用层维护。

## 3. 业务表

### 3.1 sys_dict_type + sys_dict_data 字典

字典通过 `dict_type` 字段关联（非 FK），当 `sys_dict_type.dict_type` 变更时，级联更新 `sys_dict_data` 中的所有关联记录（`SysDictDataMapper.xml:93`）。

### 3.2 sys_notice + sys_notice_read 通知公告

`sys_notice_read` 有唯一约束 `uk_user_notice(user_id, notice_id)`，确保每个用户对每条通知只有一条已读记录。

### 3.3 gen_table + gen_table_column 代码生成

`gen_table` 存储数据库表元信息，`gen_table_column` 存储字段元信息，通过 `table_id` 关联。用于代码生成器读取表结构并渲染 Velocity 模板。
