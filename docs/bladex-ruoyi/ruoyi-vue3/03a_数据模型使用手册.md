## 6. 业务关系图

```
sys_dept (部门表)
    │
    ├── 1:N ──> sys_user (用户表)
    │              │
    │              ├── N:M ──> sys_user_role ──> sys_role (角色表)
    │              │                                    │
    │              │                                    ├── N:M ──> sys_role_menu ──> sys_menu (菜单表)
    │              │                                    │
    │              │                                    └── N:M ──> sys_role_dept ──> sys_dept (数据权限)
    │              │
    │              └── N:M ──> sys_user_post ──> sys_post (岗位表)
    │
    └── 树形结构 (parentId + ancestors)

sys_dict_type (字典类型) ── 1:N ──> sys_dict_data (字典数据)

sys_notice (公告) ── N:M ──> sys_notice_read (已读记录)

sys_config (参数配置) ── 独立表，无关联

sys_oper_log (操作日志) ── 独立表，无关联
sys_logininfor (登录日志) ── 独立表，无关联
```

## 7. 树形结构说明

### 7.1 部门树（SysDept）

**维护机制：**
- `ancestors` 字段存储从根到当前节点的完整路径，逗号分隔
- 新增时：根据父部门的 ancestors + 父部门 ID 拼接
- 修改父部门时：级联更新所有子部门的 ancestors
- 启用子部门时：自动启用所有上级部门（`updateParentDeptStatusNormal`）

**查询方式：** 递归函数 `recursionFn()` 构建树形结构

### 7.2 菜单树（SysMenu）

**维护机制：**
- `parentId` 关联父菜单
- `menuType` 区分类型：M=目录, C=菜单, F=按钮
- 目录/菜单可包含子节点，按钮为叶子节点
- 路由名称全局唯一（`checkRouteConfigUnique`）

**查询方式：** 递归函数 `recursionFn()` 构建树形结构
