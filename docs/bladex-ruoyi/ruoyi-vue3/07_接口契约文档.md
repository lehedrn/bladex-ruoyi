## 2. 统一响应格式

### 2.1 成功响应

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { ... }
}
```

### 2.2 分页响应

```json
{
  "code": 200,
  "msg": "查询成功",
  "rows": [...],
  "total": 100
}
```

### 2.3 错误响应

```json
{
  "code": 500,
  "msg": "错误信息",
  "data": null
}
```

| 业务码 | 含义 | 前端处理 |
|--------|------|---------|
| 200 | 成功 | 解包 res.data |
| 401 | 未认证 | 弹窗确认 → 退出登录 |
| 500 | 服务端错误 | ElMessage.error |
| 601 | 警告 | ElMessage.warning |
| 其他 | 未知错误 | ElNotification.error |

---

## 3. 错误码清单

### 3.1 HTTP 状态码

| 状态码 | 触发场景 | 来源 |
|--------|---------|------|
| 200 | 正常响应 | AjaxResult.success() |
| 401 | 未认证/Token 过期 | AuthenticationEntryPointImpl |
| 403 | 无权限 | GlobalExceptionHandler(AccessDeniedException) |
| 404 | 路径不存在 | Spring 默认 |
| 405 | HTTP 方法不支持 | GlobalExceptionHandler |
| 500 | 服务端异常 | GlobalExceptionHandler |

### 3.2 业务错误码（ServiceException code）

| Code | 说明 | 触发场景 |
|------|------|---------|
| 500 | 通用业务错误 | ServiceException 默认 |
| 601 | 警告信息 | 前端识别为 warning |

### 3.3 前端错误码映射

**来源文件：** `src/utils/errorCode.js`

后端返回的错误码通过 errorCode 映射表转换为中文描述。

## 5. 差异修复建议

### 5.1 高优先级

| 编号 | 建议 | 操作方 | 说明 |
|------|------|--------|------|
| D-13 | 后端添加 `monitor:operlog:query` 权限接口，或前端改为使用 `monitor:operlog:list` | 前端 | 孤立权限导致按钮永远不显示（除非全通权限） |

### 5.2 中优先级

| 编号 | 建议 | 操作方 | 说明 |
