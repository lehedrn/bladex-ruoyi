> 本文档从 RuoYi-Vue3 四份分析报告中提取专业术语，按业务域分组，去重后按字母顺序排列。

| 术语 | 中文名 | 来源 | 使用场景 |

| `SysUserController` | 用户控制器 | 后端-分析报告 | /system/user 路径的 HTTP 入口 |
| `SysProfileController` | 个人中心控制器 | 后端-分析报告 | /system/user/profile 路径 |

| `SysPasswordService` | 密码服务 | 底层架构-分析报告 | BCrypt 加密 + 重试限制 |
| `SysLoginService` | 登录服务 | 底层架构-分析报告 | 完整登录流程编排 |
| `SysLogininfor` | 登录日志实体 | 后端-分析报告 | sys_logininfor 表映射 |
| `UserStatus` | 用户状态枚举 | 底层架构-分析报告 | OK / DELETED / DISABLE |

| `registerUser` | 注册用户 | 后端-分析报告 | /register 注册接口 |
| `resetPwd` | 重置密码 | 后端-分析报告 | 管理员重置用户密码 |
| `changeStatus` | 修改用户状态 | 后端-分析报告 | 启用/停用用户 |
| `authRole` | 用户授权角色 | 后端-分析报告 | 为用户分配角色 |
