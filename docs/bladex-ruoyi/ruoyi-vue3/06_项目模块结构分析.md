## 2. 模块分层说明

| 层级 | 模块 | 职责 | 依赖 |
|------|------|------|------|
| **入口层** | ruoyi-admin | Web 入口、Controller、配置 | framework + quartz + generator |
| **框架层** | ruoyi-framework | 安全、AOP、数据源、拦截器 | system |
| **业务层** | ruoyi-system | 用户/角色/菜单/部门等业务逻辑 | common |
| **工具层** | ruoyi-quartz | Quartz 定时任务 | common |
| **工具层** | ruoyi-generator | Velocity 代码生成 | common |
| **基础层** | ruoyi-common | 注解、工具、常量、实体基类 | 无 |

## 3. 前端目录结构

```

├── store/modules/           # Pinia 状态管理 (7个模块)

├── views/                   # 页面视图
│   ├── system/              # 11个业务页面 (user/role/menu/dept/post/dict/config/notice/profile)
│   ├── monitor/             # 7个监控页面 (cache/druid/job/logininfor/online/operlog/server)
│   └── tool/                # 3个工具页面 (build/gen/swagger)
```
