| user_id | BIGINT AUTO_INCREMENT | PK | 用户 ID |

| avatar | VARCHAR(100) | NULL | 头像路径 |
| password | VARCHAR(100) | DEFAULT '' | BCrypt 加密密码 |
| status | CHAR(1) | DEFAULT '0' | 状态（0正常 1停用） |
| del_flag | CHAR(1) | DEFAULT '0' | 删除标志（0存在 2删除） |

## 8. BaseEntity（审计基类）

所有业务实体继承 `BaseEntity`，自动包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| searchValue | String | 搜索值（`@JsonIgnore`，用于搜索） |
| createBy | String | 创建者 |
| createTime | String | 创建时间 |
| updateBy | String | 更新者 |
| updateTime | String | 更新时间 |
| remark | String | 备注 |
| params | Map | 请求参数（`@JsonAnyGetter`） |
