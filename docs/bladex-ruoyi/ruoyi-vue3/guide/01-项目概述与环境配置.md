## 1. 项目概述

### 1.1 项目背景

RuoYi-Vue3 是一套基于 Spring Boot + Vue 3 的前后端分离后台管理系统。项目采用经典的 RBAC 权限模型，提供用户管理、角色管理、菜单权限、系统监控、定时任务、代码生成等企业级后台管理系统常用功能。

- 项目地址：http://www.ruoyi.vip
- 开源协议：MIT
- 包名：`com.ruoyi`

### 1.2 技术栈

### 1.3 主要功能

- **用户管理**：用户增删改查、密码重置、导入导出、头像上传
- **部门管理**：树形部门结构管理，支持数据权限绑定
- **角色管理**：角色权限分配、菜单授权、数据权限范围设置
- **菜单管理**：树形菜单结构，支持目录、菜单、按钮三种类型
- **岗位管理**：岗位信息维护
- **字典管理**：字典类型与字典数据的维护，前端通过 DictTag 组件渲染
- **参数配置**：系统动态参数配置
- **通知公告**：公告发布与已读记录追踪
- **操作日志**：通过 `@Log` 注解自动记录，支持异步写入
- **登录日志**：记录登录 IP、浏览器、操作系统等信息
- **在线用户**：查看在线用户，支持强制下线
- **定时任务**：基于 Quartz 的定时任务管理，支持 Cron 表达式
- **代码生成**：从数据库表自动生成前后端 CRUD 代码
- **服务监控**：CPU、内存、磁盘、JVM 信息查看
- **缓存监控**：Redis 缓存查看与操作
- **系统接口**：SpringDoc 自动生成 Swagger UI

### 2.2 后端环境搭建

#### 2.2.1 克隆源码

```bash
git clone <repo-url>
cd sources/ruoyi/ruoyi-vue3
```

#### 2.2.2 数据库初始化

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE `ry-vue` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

# 导入表结构
use ry-vue;
source sql/ry_20260417.sql;

# 如果需要定时任务功能，导入 Quartz 表
source sql/quartz.sql;
```

#### 2.2.3 修改配置文件

编辑 `ruoyi-admin/src/main/resources/application-druid.yml`：

```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
        username: root
        password: <your-password>
```

编辑 `ruoyi-admin/src/main/resources/application.yml` 中的 Redis 配置：

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      password: <your-redis-password-if-any>
      database: 0
```

#### 2.2.4 编译并启动后端

```bash
# 在项目根目录执行
mvn clean install

# 启动
cd ruoyi-admin
mvn spring-boot:run

# 或者直接运行 main 类 com.ruoyi.RuoYiApplication
```

#### 2.2.5 使用脚本启停（生产/测试）

```bash
# 先打包
mvn clean package -DskipTests
cp ruoyi-admin/target/ruoyi-admin.jar ./

# 启动
./ry.sh start

# 停止
./ry.sh stop

# 重启
./ry.sh restart

# 查看状态
./ry.sh status
```

默认启动参数：
- JVM: `-Xms512m -Xmx1024m -XX:MetaspaceSize=128m -XX:MaxMetaspaceSize=512m`
- JAR: `ruoyi-admin.jar`

### 2.3 前端环境搭建

```bash
cd ruoyi-ui

npm run dev

## 3. 功能模块说明

### 3.1 ruoyi-admin（Web 入口模块）

**职责**：项目启动入口、Controller 层、配置文件。

**包结构**：
```
com.ruoyi/
├── RuoYiApplication.java          # 启动类
├── RuoYiServletInitializer.java   # Servlet 容器初始化
├── web/
│   ├── controller/
│   │   ├── common/                # 通用接口
│   │   │   ├── CaptchaController  # 验证码生成
│   │   │   └── CommonController   # 文件下载
│   │   ├── monitor/               # 监控接口
│   │   ├── system/                # 系统管理接口
│   │   └── tool/                  # 工具接口
│   └── core/                      # Admin 专属核心组件
```

**启动流程**：
1. `RuoYiApplication.main()` 启动 Spring Boot
2. `@SpringBootApplication` 排除 `DataSourceAutoConfiguration`（由 Druid 自定义数据源）
3. 加载配置文件：`application.yml` + `application-druid.yml`（profile: druid）
4. Spring Security 拦截所有请求，配置无状态会话
5. 开放 Swagger、Druid、登录、注册、验证码等匿名路径
6. JWT 过滤器拦截带 Token 的请求

### 3.2 ruoyi-framework（框架核心模块）

**职责**：安全认证、数据源、缓存、切面、过滤器、Web 配置。

**核心组件**：

| 组件 | 文件 | 说明 |
|------|------|------|
| SecurityConfig | `config/SecurityConfig.java` | Spring Security 过滤链配置 |
| JwtAuthenticationTokenFilter | `security/filter/JwtAuthenticationTokenFilter.java` | JWT Token 验证过滤器 |
| TokenService | `web/service/TokenService.java` | Token 生成/解析/刷新，Redis 存储 |
| SysLoginService | `web/service/SysLoginService.java` | 登录流程：验证码校验 → 用户认证 → Token 生成 |
| SysPermissionService | `web/service/SysPermissionService.java` | 解析用户角色与权限列表 |
| PermissionService | `web/service/PermissionService.java` | `@ss` Bean，供 `@PreAuthorize` 调用 |
| DataScopeAspect | `aspectj/DataScopeAspect.java` | 数据权限过滤切面 |
| LogAspect | `aspectj/LogAspect.java` | 操作日志记录切面 |
| RateLimiterAspect | `aspectj/RateLimiterAspect.java` | 接口限流切面 |
| RepeatSubmitInterceptor | `interceptor/RepeatSubmitInterceptor.java` | 防重复提交拦截器 |
| RedisConfig | `config/RedisConfig.java` | Redis 连接 + FastJson2 序列化 |
| DruidConfig | `config/DruidConfig.java` | Druid 数据源配置 |
| MyBatisConfig | `config/MyBatisConfig.java` | MyBatis SqlSessionFactory 配置 |

**认证流程**：
```
客户端请求
  → JwtAuthenticationTokenFilter 解析 Authorization Header
  → TokenService.validateToken() 校验 Redis 中的 Token 有效性
  → 自动续期（剩余时间 < 20 分钟时刷新）
  → Spring Security 设置 Authentication
  → @PreAuthorize("@ss.hasPermi('xxx')") 权限校验
  → Controller 方法
```

**数据权限 5 种范围**（由 `@DataScope` 切面实现）：

| 范围 | 值 | 说明 |
|------|----|------|
| 全部数据 | 1 | 不做过滤 |
| 自定义数据 | 2 | 按 `sys_role_dept` 表配置的部门过滤 |
| 本部门数据 | 3 | 仅当前用户所在部门 |
| 本部门及以下 | 4 | 当前部门及子部门（递归） |
| 仅本人数据 | 5 | 仅 `create_by` 为当前用户的记录 |

### 3.3 ruoyi-system（系统业务模块）

**职责**：所有系统管理的 Service 层、Mapper 层、Domain 实体。

**业务组**（每组包含 Interface + Impl + Mapper + XML）：

| 业务 | 接口 | Mapper | 实体 |
|------|------|--------|------|
| 用户 | `ISysUserService` | `SysUserMapper` | `SysUser` |
| 角色 | `ISysRoleService` | `SysRoleMapper` | `SysRole` |
| 菜单 | `ISysMenuService` | `SysMenuMapper` | `SysMenu` |
| 部门 | `ISysDeptService` | `SysDeptMapper` | `SysDept` |
| 岗位 | `ISysPostService` | `SysPostMapper` | `SysPost` |
| 字典类型 | `ISysDictTypeService` | `SysDictTypeMapper` | `SysDictType` |
| 字典数据 | `ISysDictDataService` | `SysDictDataMapper` | `SysDictData` |
| 参数配置 | `ISysConfigService` | `SysConfigMapper` | `SysConfig` |
| 通知公告 | `ISysNoticeService` | `SysNoticeMapper` | `SysNotice` |
| 已读记录 | `ISysNoticeReadService` | `SysNoticeReadMapper` | `SysNoticeRead` |
| 操作日志 | `ISysOperLogService` | `SysOperLogMapper` | `SysOperLog` |
| 登录日志 | `ISysLogininforService` | `SysLogininforMapper` | `SysLogininfor` |

**辅助实体**：`SysUserRole`、`SysRoleMenu`、`SysRoleDept`、`SysUserPost`（关联表实体）、`MetaVo`（前端路由元信息）、`RouterVo`（前端路由对象）。

### 3.4 ruoyi-common（通用工具模块）

**职责**：全局共享的注解、工具类、异常处理、通用响应体。

**核心注解**（`annotation/`）：

| 注解 | 用途 |
|------|------|
| `@Log` | 操作日志记录，标注在 Controller 方法上 |
| `@DataScope` | 数据权限过滤，标注在 Service 方法上 |
| `@DataSource` | 动态数据源切换（主从） |
| `@RateLimiter` | 接口限流 |
| `@RepeatSubmit` | 防重复提交 |
| `@Anonymous` | 匿名访问，不需要认证 |
| `@Sensitive` | 数据脱敏 |
| `@Excel` / `@Excels` | Excel 导入导出字段映射 |
| `@Xss` | XSS 校验 |

**通用响应体**（`core/domain/`）：
- `AjaxResult`：标准响应体，包含 `code`（200=成功）、`msg`、`data`
- `R<T>`：泛型响应体
- `TableDataInfo`：分页响应体，包含 `rows`、`total`、`code`、`msg`

**工具类**（`utils/`）：`SecurityUtils`、`ServletUtils`、`StringUtils`、`DateUtils`、`DictUtils`、`Arith`（算术运算）、`PageUtils`、`IpUtils`、`MessageUtils`、`SpringUtils`、`FileUtils`、`ExcelUtil`、`Md5Utils`、`IdUtils` 等。

### 3.5 ruoyi-quartz（定时任务模块）

**职责**：基于 Quartz 的定时任务管理。

**核心类**：
- `SysJob`：任务实体，包含任务名称、调用目标、Cron 表达式、执行策略、状态等
- `SysJobLog`：任务执行日志实体
- `AbstractQuartzJob`：任务基类，处理执行前后回调和异常
- `SysJobController`：任务 CRUD、立即执行、状态变更
- `SysJobLogController`：日志查询与清理

**任务调用目标格式**：`beanName.methodName('params')`，例如 `ryTask.userTask('admin')`。

**执行流程**：
```
Cron 触发 → AbstractQuartzJob.execute()
  → 记录开始时间 → 调用目标方法
  → 成功：记录输出 → 失败：记录异常信息
  → 更新 sys_job_log 表
```

### 3.6 ruoyi-generator（代码生成模块）

**职责**：从数据库表元数据自动生成前后端 CRUD 代码。

**核心类**：
- `GenTable`：代码生成表实体，包含表名、类名、模板类型、包名等配置
- `GenTableColumn`：列实体，包含列名、Java 类型、是否主键、是否必填等
- `GenController`：代码生成接口，支持预览、下载、导入

**支持模板**：
- Java：Entity、Mapper、Service、Controller
- XML：Mapper XML
- Vue：列表页、表单页
- SQL：菜单 SQL

**生成流程**：
```
选择数据库表 → 导入到 gen_table → 配置字段属性
  → 选择模板类型（单表/树表/主子表）
  → 预览代码 → 下载 ZIP 或导入到项目
```

### 3.7 模块间交互关系

```
┌─────────────────────────────────────────┐
│  ruoyi-admin (Controller)               │
│  接收请求 → 调用 Service → 返回 AjaxResult│
└──────────┬──────────────────────────────┘
           │
           ▼
┌─────────────────────────────────────────┐
│  ruoyi-system (Service + Mapper)        │
│  业务逻辑 → 调用 Mapper → 返回领域对象   │
└──────────┬──────────────────────────────┘
           │
           ▼

框架层（ruoyi-framework）横向切入：
- Security 过滤链拦截所有 Controller 请求
- 切面（`@Log`、`@DataScope`、`@RateLimiter`）在 Service/Controller 层织入
- 拦截器（`RepeatSubmit`、`XssFilter`）在 Servlet 层织入
