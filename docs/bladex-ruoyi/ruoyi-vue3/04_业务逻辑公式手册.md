# 04 业务逻辑公式手册

> 本文档从后端、前端、接口契约分析报告中提取计算规则、校验规则、状态机流转规则，按规则分类组织。

---

## 1. 计算规则

### 1.1 Token 生成与续期

| 规则 | 类型 | 说明 |
|------|------|------|
| Token 标识 = UUID v4 | 显式 | `TokenService.createToken()` 中使用 `UUID.randomUUID().toString()` |
| Redis Key = `login_tokens:` + UUID | 显式 | `CacheConstants.LOGIN_TOKEN_KEY` + uuid |
| Token 过期时间 = 当前时间 + `token.expireTime`（分钟） | 显式 | `refreshToken()` 中计算 |
| 自动续期触发 = `expireTime - currentTime < 20分钟` | 显式 | `verifyToken()` 中判断 |
| JWT 载荷 = `{login_user_key: uuid, sub: username}` | 显式 | Jwts.builder() 构建 |
| JWT 签名算法 = HS512 | 显式 | `SecretKey` 签名 |

### 1.2 数据权限 SQL 拼接

| dataScope | 生成的 SQL 片段 | 来源 |
|-----------|----------------|------|
| `1` 全部数据 | 空（不限制） | DataScopeAspect |
| `2` 自定义数据 | `OR dept_id IN (SELECT dept_id FROM sys_role_dept WHERE role_id = ?)` | DataScopeAspect |
| `3` 本部门 | `OR dept_id = ?` | DataScopeAspect |
| `4` 本部门及以下 | `OR dept_id IN (SELECT dept_id FROM sys_dept WHERE find_in_set(?, ancestors))` | DataScopeAspect |
| `5` 仅本人 | `OR user_id = ?` | DataScopeAspect |

**拼接规则：**
- 多个自定义数据权限角色时合并为 `IN (...)` 避免多次拼接
- 超级管理员（roleId=1）不执行任何过滤
- 最终注入到 `BaseEntity.params.dataScope`，MyBatis XML 用 `${dataScope}` 引用

### 1.3 防重复提交判定

| 规则 | 公式 | 来源 |
|------|------|------|
| 缓存 Key | `repeat_submit:{URL}{Token}` | SameUrlDataInterceptor |
| 缓存 Value | `{url, repeatParams: 参数JSON, repeatTime: 时间戳}` | SameUrlDataInterceptor |
| 判定为重复 | `参数相同 && (当前时间 - repeatTime) < interval` | SameUrlDataInterceptor |
| 默认间隔 | 5000ms | `@RepeatSubmit.interval()` |

**前端防重复（Axios 拦截器）：**
- Key = `url + JSON.stringify(data) + timestamp`
- 间隔默认 1000ms，可通过 `config.headers.interval` 覆盖

### 1.4 限流计数

| 规则 | 公式 | 来源 |
|------|------|------|
| Key 格式（DEFAULT） | `rate_limit:{类名}-{方法名}` | RateLimiterAspect |
| Key 格式（IP） | `rate_limit:{IP}:{类名}-{方法名}` | RateLimiterAspect |
| 计数逻辑 | Redis INCR + EXPIRE（Lua 脚本） | RedisConfig.limitScript |
| 超限动作 | 抛出 ServiceException("访问过于频繁，请稍候再试") | RateLimiterAspect |

### 1.5 部门 ancestors 维护

| 操作 | 规则 | 来源 |
|------|------|------|
| 新增部门 | `ancestors = 父部门.ancestors + "," + 父部门ID` | SysDeptServiceImpl.insertDept() |
| 修改父部门 | 级联更新所有子部门的 ancestors | SysDeptServiceImpl.updateDept() |
| 查询下级部门 | `WHERE find_in_set(部门ID, ancestors)` | SysDeptMapper.selectNormalChildrenDeptById() |

### 1.6 通知公告顶部查询

| 规则 | 说明 | 来源 |
|------|------|------|
| 数量限制 | 最多 5 条 | SysNoticeController.listTop() |
| 已读标记 | 查询 `sys_notice_read` 表，匹配当前用户 ID | SysNoticeReadMapper |

## 2. 校验规则

### 2.1 用户管理校验

#### 后端校验（@Validated + 实体注解 + Service 逻辑）

| 字段 | 校验规则 | 类型 | 来源 |
|------|---------|------|------|
| userName | @NotBlank, @Size(max=30), 唯一性 | 显式 | SysUser.java, SysUserController |
| nickName | @Size(max=30) | 显式 | SysUser.java |
| email | @Email, @Size(max=50), 唯一性 | 显式 | SysUser.java, SysUserController |
| phonenumber | @Size(max=11), 唯一性 | 显式 | SysUser.java, SysUserController |
| 密码 | BCrypt 加密 | 隐式 | SysUserController |
| 密码长度 | 5-20 字符 | 显式 | SysLoginService.loginPreCheck() |
| 用户名长度 | 2-20 字符 | 显式 | SysLoginService.loginPreCheck() |
| 超级管理员保护 | roleId=1 不允许操作 | 隐式 | SysUserServiceImpl.checkUserAllowed() |
| 当前用户保护 | 不允许删除当前登录用户 | 隐式 | SysUserController.remove() |
| 用户名唯一 | 全局唯一 | 隐式 | SysUserServiceImpl.checkUserNameUnique() |
| 手机号唯一 | 全局唯一 | 隐式 | SysUserServiceImpl.checkPhoneUnique() |
| 邮箱唯一 | 全局唯一 | 隐式 | SysUserServiceImpl.checkEmailUnique() |

#### 前端校验（Element Plus rules）

| 字段 | 校验规则 | 类型 | 来源 |
|------|---------|------|------|
| userName | required, min:2, max:20 | 显式 | user/index.vue |
| nickName | required | 显式 | user/index.vue |
| email | type: "email" | 显式 | user/index.vue |
| phonenumber | pattern: `^1[3-9][0-9]\d{8}$` | 显式 | user/index.vue |
| password | usePasswordRule() 自定义 | 显式 | user/index.vue |

#### 前后端差异

| 校验项 | 后端 | 前端 | 差异 |
|--------|------|------|------|
| userName 最大长度 | 30 | 20 | ⚠️ 前端更严格 |
| nickName 非空 | 无 | required | ⚠️ 前端更严格 |
| phonenumber 格式 | 无格式校验 | 正则校验 | ⚠️ 前端更严格 |

## 3. 状态机流转规则

### 3.1 用户状态流转

```
正常(0)
  │
  ├── 管理员修改状态 → 停用(1)
  │     └── 用户无法登录（UserDetailsServiceImpl 检查 status）
  │
  └── 停用(1)
        └── 管理员修改状态 → 正常(0)
              └── 恢复登录能力

删除标记:
  │
  ├── 正常(0) → 逻辑删除(1)
  │     └── 用户从列表中隐藏，无法登录
  │
  └── 逻辑删除(1)
        └── 不允许恢复（需管理员手动处理）
```

### 3.2 角色状态流转

```
正常(0)
  │
  ├── 修改状态 → 停用(1)
  │     └── 持有该角色的用户失去对应权限
  │     └── TokenService.refreshPermissionByRoleId() 刷新在线用户
  │
  └── 停用(1)
        └── 修改状态 → 正常(0)

删除标记:
  │
  ├── 正常(0) → 逻辑删除(1)
  │     └── 有用户关联时不允许删除
  │
  └── 逻辑删除(1)
        └── 不允许恢复
```

### 3.3 菜单状态流转

```
正常(0)
  │
  ├── 修改状态 → 停用(1)
  │     └── 持有该菜单权限的用户无法访问
  │
  └── 停用(1)
        └── 修改状态 → 正常(0)

删除:
  │
  ├── 存在子菜单 → 不允许删除
  │
  └── 已分配给角色 → 不允许删除
```

### 3.4 部门状态流转

```
正常(0)
  │
  ├── 修改状态 → 停用(1)
  │     └── 包含未停用子部门时不允许
  │     └── 子部门不受影响（不级联停用）
  │
  └── 停用(1)
        └── 修改状态 → 正常(0)
              └── 自动启用所有上级部门

启用子部门:
  │
  └── 父部门停用 → 不允许新增
  └── 修改父部门为正常 → 自动启用上级部门链

删除:
  │
  ├── 部门下有用户 → 不允许删除
  │
  └── 存在下级部门 → 不允许删除
```

### 3.5 定时任务状态流转

```
正常(暂停)
  │
  ├── 修改状态 → 运行中
  │     └── 加入 Quartz 调度
  │
  └── 运行中
        ├── 修改状态 → 暂停
        │     └── 从 Quartz 调度中移除
        │
        └── 执行一次 → 立即执行一次(不改变状态)
```

### 3.6 公告状态流转

```
正常(0)
  │
  ├── 修改状态 → 关闭(1)
  │     └── 首页不再显示
  │
  └── 关闭(1)
        └── 修改状态 → 正常(0)

已读标记:
  │
  ├── 用户点击公告 → markRead → 写入 sys_notice_read
  │
  └── 一键已读 → markReadAll → 批量写入
```

### 3.7 通知已读状态

```
未读
  │
  ├── 点击公告 → POST /markRead
  │     → 写入 (noticeId, userId) 到 sys_notice_read
  │     → 标记为已读
  │
  └── 一键已读 → POST /markReadAll
        → 批量写入所有未读公告的已读记录
        → 标记为已读
```

## 4. 权限规则

### 4.1 权限标识格式

```
模块:功能:操作

示例:
  system:user:list    -- 系统模块/用户/列表
  system:user:add     -- 系统模块/用户/新增
  system:user:edit    -- 系统模块/用户/修改
  system:user:remove  -- 系统模块/用户/删除
  system:user:query   -- 系统模块/用户/查询
  system:user:export  -- 系统模块/用户/导出
  system:user:import  -- 系统模块/用户/导入
  system:user:resetPwd -- 系统模块/用户/重置密码
```

### 4.2 全通标识

| 场景 | 标识 | 效果 |
|------|------|------|
| 后端 | `*:*:*` | PermissionService.hasPermi() 直接返回 true |
| 前端 | `*:*:*` | v-hasPermi 指令直接放行 |

### 4.3 角色超级管理员

| 场景 | 标识 | 效果 |
|------|------|------|
| 后端 | 角色 key = "admin" | PermissionService.hasRole() 直接返回 true |
| 前端 | 角色 = "admin" | v-hasRole 指令直接放行 |

### 4.4 数据权限规则

| dataScope | 名称 | 过滤条件 |
|-----------|------|---------|
| 1 | 全部数据 | 不限制 |
| 2 | 自定义数据 | 关联 sys_role_dept 表查询 |
| 3 | 本部门 | dept_id = 当前用户部门 ID |
| 4 | 本部门及以下 | ancestors 包含当前用户部门 ID |
| 5 | 仅本人 | user_id = 当前用户 ID |

## 6. 密码规则

### 6.1 密码加密

| 规则 | 说明 | 来源 |
|------|------|------|
| 加密算法 | BCrypt | SecurityUtils.encryptPassword() |
| 加密时机 | 新增用户/修改密码/重置密码时 | SysUserController |
| 密码传输 | 明文（登录），RSA 加密（记住密码） | login.vue |
| 密码对比 | BCrypt.matches() 验证 | BCryptPasswordEncoder |

### 6.2 密码重试限制

| 规则 | 公式 | 来源 |
|------|------|------|
| Redis Key | `pwd_err_cnt:{username}` | SysPasswordService |
| 锁定条件 | 失败次数 > `user.password.maxRetryCount` | SysPasswordService |
| 锁定时间 | `user.password.lockTime` 分钟 | SysPasswordService |
| 解锁方式 | 清除 Redis 中的 pwd_err_cnt | SysLogininforController.unlock() |

### 6.3 密码过期策略

| 规则 | 配置项 | 说明 |
|------|--------|------|
| 密码有效期 | `sys.account.passwordValidateDays` | 超过天数提示修改 |
| 初始密码提醒 | `sys.account.initPasswordModify` | 检测到未修改初始密码时提示 |
| 密码自定义规则 | `sys.account.chrtype` | 后端配置密码规则类型 |

## 7. 隐式规则清单

| 编号 | 规则 | 类型 | 影响 |
|------|------|------|------|
| I-01 | 唯一性校验仅在后端（角色名/菜单名/部门名等） | 隐式 | 用户需提交后才知道冲突 |
| I-02 | 角色权限变更后自动刷新在线用户 | 隐式 | 前端无感知，自动生效 |
| I-03 | 字典类型变更时同步更新关联字典数据 | 隐式 | 前端无感知，自动生效 |
| I-04 | ancestors 自动维护 | 隐式 | 前端无感知，后端自动维护 |
| I-05 | 密码重试次数锁定 | 隐式 | 前端通过错误提示感知 |
| I-06 | 参数配置启动时全量加载到 Redis | 隐式 | 查询优先读缓存 |
| I-07 | 字典数据启动时分组加载到 Redis | 隐式 | 查询优先读缓存 |
| I-08 | 操作日志异步写入（延迟 10ms） | 隐式 | 不阻塞业务 |
| I-09 | 登录日志异步写入 | 隐式 | 不阻塞登录流程 |
| I-10 | 前端防重复提交开关可通过 header 关闭 | 隐式 | `config.headers.repeatSubmit = false` |
