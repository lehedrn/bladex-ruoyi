## 1. 计算公式

### 1.1 Token 过期时间计算

**来源：** `ruoyi-framework/.../web/service/TokenService.java`

```
expireTime = loginTime + (expireTime 配置值 × 60 × 1000)
```

- 默认 `expireTime` = 30 分钟（`application.yml: token.expireTime`）
- 自动续期条件：`expireTime - currentTime <= 20 分钟`

### 1.2 JWT 签名

```
JWT = Jwts.builder()
  .setClaims({ LOGIN_USER_KEY: uuid, sub: username })
  .signWith(SignatureAlgorithm.HS512, secret)
  .compact()
```

- 签名算法：HS512
- Secret 配置：`token.secret`（默认 `abcdefghijklmnopqrstuvwxyz`）
- JWT payload 中仅存 UUID 引用和用户名，不包含用户详细信息

### 1.3 密码 BCrypt 哈希

```
存储密码 = BCrypt.hashpw(原始密码, BCrypt.gensalt())
验证密码 = BCrypt.checkpw(原始密码, 存储密码)
```

- 工具方法：`SecurityUtils.matchesPassword(raw, encoded)`

### 2.2 密码重试锁定

**来源：** `SysPasswordService.java`

```
Redis key: PWD_ERR_CNT_KEY + username
maxRetryCount: sys_config 配置（默认 5 次）
lockTime: sys_config 配置（默认 10 分钟）

if (retryCount >= maxRetryCount) → 抛出 UserPasswordRetryLimitExceedException
密码错误 → retryCount + 1, TTL = lockTime 分钟
密码正确 → clearLoginRecordCache()
```

## 3. 数据权限 SQL 生成规则

**来源：** `DataScopeAspect.java:90-127`

遍历用户的所有角色，按角色 `data_scope` 生成 SQL 片段：

```java
// 注入到 BaseEntity.params["dataScope"]
// 最终在 MyBatis XML 中通过 ${params.dataScope} 拼接

// DATA_SCOPE_ALL (1):  直接 break，不添加任何过滤
// DATA_SCOPE_CUSTOM (2): OR dept_id IN (SELECT dept_id FROM sys_role_dept WHERE role_id IN (...))
// DATA_SCOPE_DEPT (3):  OR dept_id = #{currentDeptId}
// DATA_SCOPE_DEPT_AND_CHILD (4): OR dept_id IN (SELECT dept_id FROM sys_dept WHERE find_in_set(#{deptId}, ancestors))
// DATA_SCOPE_SELF (5):  OR user_id = #{currentUserId}

// 无任何角色匹配时:
OR dept_id = 0  // 导致查不到任何数据
```

**隐式条件：**
- 超级管理员（userId==1）跳过整个数据权限计算
- 角色状态为 `ROLE_DISABLE` 的不参与计算
- 多个角色时，遇到 DATA_SCOPE_ALL 直接 break（取最高权限）

## 4. 部门树 ancestors 计算规则

**来源：** `SysDeptServiceImpl.java:213-282`

### 新增部门
```
ancestors = parentDept.ancestors + "," + parentDept.deptId
示例: "0,100" + "," + "101" = "0,100,101"
```

### 修改部门父级
```sql
-- 批量更新当前部门及所有子孙的 ancestors
UPDATE sys_dept SET ancestors = CASE dept_id
  WHEN #{deptId} THEN #{newAncestors}
  WHEN #{childId1} THEN REPLACE(old_ancestors, #{oldPath}, #{newPath})
  ...
END
WHERE dept_id IN (...)
```

### 查询子部门
```sql
-- 查询某部门的所有子孙
SELECT * FROM sys_dept WHERE find_in_set(#{deptId}, ancestors)
```

## 5. 菜单路由构建规则

**来源：** `SysMenuServiceImpl.java:173-222`

| 菜单类型 | 前端路由生成规则 |
|----------|-----------------|
| M (目录) 一级 + isFrame=1 | path = "/" + menu.path, alwaysShow=true, redirect="noRedirect" |
| C (菜单) 一级 + isFrame=1 | path = "/", component 为实际组件（内跳转） |
| 外链 (isFrame=1, path 以 http 开头) | path 做特殊字符替换: http://, https://, www., ., : |
| F (按钮) | 不生成路由，仅用于 @PreAuthorize 权限控制 |

## 6. 系统配置项业务规则
