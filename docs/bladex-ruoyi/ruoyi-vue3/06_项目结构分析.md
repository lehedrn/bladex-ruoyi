# 06 项目结构分析

> 本文档分析 RuoYi-Vue3 的后端 Maven 多模块结构和前端 Vite + Vue3 项目结构。

---

## 1. 后端目录结构

### 1.1 顶层 Maven 模块

```
ruoyi/
├── pom.xml                          # 父 POM，管理依赖版本
├── ruoyi-admin/                     # Web 入口层（Controller）
├── ruoyi-framework/                 # 框架层（Security/AOP/Filter）
├── ruoyi-system/                    # 业务层（Service + Mapper）
├── ruoyi-common/                    # 公共模块（实体/工具/注解）
├── ruoyi-quartz/                    # 定时任务模块（可选）
└── ruoyi-generator/                 # 代码生成模块（可选）
```

## 3. 模块职责说明

### 3.1 后端模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| ruoyi-admin | HTTP 入口，Controller 层，接收/响应请求 | framework, system, quartz, generator |
| ruoyi-framework | 安全框架、AOP 切面、Filter、拦截器、数据源、异步任务 | common |
| ruoyi-system | 业务 Service + Mapper，数据库操作 | common |
| ruoyi-common | 实体类、工具类、注解、枚举、异常、Redis 封装、分页模型 | 无 |
| ruoyi-quartz | 定时任务管理（Quartz 集成） | common, framework |
| ruoyi-generator | 代码生成器（Velocity 模板） | common |

### 3.2 前端模块

| 模块 | 职责 | 关键文件 |
|------|------|---------|
| router | 路由配置 + 动态路由注册 | router/index.js |
| store | Pinia 状态管理（7 个模块） | store/modules/ |
| api | 后端接口封装（19 个模块） | api/ |
| directive | 自定义指令（权限/角色/复制） | directive/ |
| plugins | 全局插件（弹窗/权限/页签/缓存/下载） | plugins/ |
| utils | 工具函数（Axios/字典/验证/加密等） | utils/ |
| views | 业务页面（44 个 Vue 组件） | views/ |
| components | 通用组件（29 个 Vue 组件） | components/ |
| layout | 布局骨架（17 个 Vue 组件） | layout/ |
