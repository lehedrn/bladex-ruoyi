## 2. 布局组件

### 2.1 Layout（主布局）

**来源：** `src/layout/index.vue`

**结构：**
```
Layout
├── Sidebar (侧边栏)
│   ├── Logo
│   └── SidebarItem (递归)
├── Main Container
│   ├── Navbar (顶部导航栏)
│   ├── TagsView (页签栏)
│   │   └── ScrollPane
│   └── AppMain (主内容区)
│       ├── <router-view> + <keep-alive>
│       ├── IframeToggle
│       └── Copyright
└── Settings (布局设置抽屉)
```

**状态来源：**
- 侧边栏展开 → `appStore.sidebar.opened`
- 设备类型 → `appStore.device`
- 页签列表 → `tagsViewStore.visitedViews`
- 主题色 → `settingsStore.theme`

### 2.2 TagsView（页签栏）

**来源：** `src/layout/components/TagsView/index.vue`

**特性：**
- 两种样式：`card`（卡片）和 `chrome`（Chrome 风格）
- 左右箭头滚动导航
- 右键上下文菜单（刷新/关闭/关闭其他/关闭左侧/关闭右侧/全部关闭）
- 下拉操作菜单（同上 + 全屏显示）
- 支持 `affix` 固定标签（首页）
- 支持持久化（localStorage，受 `settingsStore.tagsViewPersist` 控制）

### 2.3 AppMain（主内容区）

**来源：** `src/layout/components/AppMain.vue`

**功能：**
- `<router-view>` 渲染路由组件
- `<keep-alive :include="tagsViewStore.cachedViews">` 缓存组件
- 通过 `route.meta.noCache` 控制是否缓存
- 支持 iframe 外链页面（`route.meta.link`）

### 2.4 Sidebar（侧边栏）

**来源：** `src/layout/components/Sidebar/index.vue`

**数据来源：** `permissionStore.sidebarRouters`

**主题：** 支持 dark/light，通过 CSS `v-bind()` 动态绑定菜单背景/文字颜色。

## 4. 交互状态机

### 4.1 登录状态机

```
[未登录]
  │
  ├── 用户输入账号/密码/验证码 → login.vue
  │     → userStore.login() → POST /login
  │     ├── 成功 → setToken → unlockScreen() → 跳转首页
  │     └── 失败 → ElMessage 提示错误
  │
  ├── permission.js 守卫检测 Token
  │     → getInfo() → 获取用户信息/角色/权限
  │     → generateRoutes() → 获取路由树 → addRoute()
  │     → redirect 到目标页面
  │
  └── Token 过期/401
        → ElMessageBox 确认 → logOut() → 清除 Token → 跳转登录页
```

### 4.2 页面缓存状态机

```
路由变更
  │
  ├── TagsView 监听路由变化
  │     → addView(view) → visitedViews.push() + cachedViews.push(name)
  │
  ├── AppMain <keep-alive :include="cachedViews">
  │     → 组件被缓存（不销毁）
  │
  ├── 刷新页面 ($tab.refreshPage)
  │     → delCachedView(view) → 移除缓存
  │     → router.replace('/redirect/' + path) → 重定向中转页
  │     → 立即 router.replace 回来 → 组件重新挂载
  │
  └── 关闭页签 ($tab.closePage)
        → delView(view) → 移除 visitedViews + cachedViews
        → 组件销毁（onUnmounted 触发）
```

### 4.3 锁屏状态机

```
[正常状态]
  │
  ├── 用户点击锁屏 → lockStore.lockScreen(currentPath)
  │     → isLock = true, lockPath = currentPath
  │     → permission.js 守卫拦截 → 重定向 /lock
  │
  ├── 锁屏页面输入密码 → POST /unlockscreen
  │     ├── 成功 → lockStore.unlockScreen() → isLock = false → 返回 lockPath
  │     └── 失败 → 提示密码错误
  │
  └── Token 过期/登出 → lockStore.unlockScreen()（自动解锁）→ 跳转登录页
```

### 4.4 权限加载状态机

```
首次访问(有 Token)
  │
  ├── router.beforeEach
  │     → roles 为空
  │     → isRelogin.show = true (防重复)
  │     → getInfo()
  │          → 401 → logOut() → 跳转登录
  │          → 成功 → userStore 填充 roles/permissions
  │     → generateRoutes()
  │          → 后端返回路由树 → filterAsyncRouter()
  │          → 前端动态路由按权限过滤
  │          → addRoute() 注册
  │     → return { ...to, replace: true } (重新导航)
  │
  └── 后续访问 → roles 非空 → 直接放行
```

### 4.5 字典加载状态机

```
组件使用 useDict("dictType1", "dictType2")
  │
  ├── 遍历每个 dictType
  │     → dictStore.getDict(key)
  │     ├── 命中缓存 → 直接返回
  │     └── 未命中
  │          → GET /system/dict/data/type/{dictType}
  │          → dictStore.setDict(key, data) 写入缓存
  │          → 返回数据
  │
  └── 字典数据变更
        → 后端 refreshCache 接口
        → 前端需刷新页面重新获取
```
