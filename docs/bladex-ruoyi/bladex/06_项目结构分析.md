## 第2章：各模块职责说明

### 2.1 blade-core-tool（工具类库）

- 提供 40+ 工具类（字符串、日期、加密、序列化、反射等）
- Jackson 定制配置（JsonUtil 单例）
- 消息解析器、敏感词过滤
- 被几乎所有其他模块依赖

### 2.2 blade-core-boot（Web 启动）

- Web MVC 配置（BladeWebMvcConfiguration）
- 请求包装、重试配置
- AOP 启用（@EnableAspectJAutoProxy）

### 2.3 blade-core-secure（安全认证）

- 多拦截器链（Basic/Sign/Token/Client）
- 权限切面（@PreAuth/@IsAdmin/@IsAdministrator）
- Nonce 防重放、签名验证

### 2.4 blade-core-oauth2（OAuth2 认证）

- Token 授予（5 种 Granter）
- Token 端点（/oauth/token）
- OAuth2 异常处理

### 2.5 blade-starter-mybatis（MyBatis-Plus）

- 分页插件、SQL 日志
- 租户过滤（TenantLineInnerInterceptor）
- Mapper 自动扫描

### 2.6 blade-starter-tenant（多租户）

- SQL 级租户隔离
- 异步租户传播（@TenantAsync）
- 租户忽略（@TenantIgnore）

### 2.7 业务模块职责

| 模块 | 路径 | 职责 |
|------|------|------|
| system | /blade-system | 用户、角色、菜单、部门、租户、字典等核心管理 |
| desk | /blade-desk | 公告、请假流程示例 |
| resource | /blade-resource | OSS、附件、短信配置 |
| develop | /blade-develop | 代码生成、数据源、数据模型 |
| flow | /blade-flow | 流程定义、部署、待办/已办 |
| job | /blade-job | 任务信息、任务服务 |
| log | /blade-log | 常规日志、错误日志、API 日志 |

## 第3章：模块间依赖关系

### 3.1 底层 Starter 依赖

```
blade-starter-mybatis
  ├── 依赖 blade-core-tool, blade-core-secure(AuthUtil)
  └── 被 blade-starter-tenant 依赖

blade-starter-tenant
  ├── 依赖 blade-starter-mybatis, blade-core-context
  └── 被 blade-starter-tenant-dynamic 依赖

blade-starter-redis
  ├── 依赖 blade-core-tool
  └── 被 blade-starter-jwt 依赖

blade-starter-jwt
  └── 依赖 blade-starter-redis

blade-starter-cache
  └── 依赖 blade-starter-redis (RedisCacheManager)

blade-starter-oss
  └── 依赖 blade-core-tool

blade-starter-log
  ├── 依赖 blade-core-launch (ServerInfo, BladeProperties)
  └── 依赖 blade-core-context

blade-starter-data-record
  ├── 依赖 blade-starter-mybatis, blade-core-launch
  └── AutoConfigureBefore MybatisPlusConfiguration

blade-starter-sharding
  └── 依赖 blade-starter-db-dynamic, blade-starter-tenant
```

详见 `底层架构-分析报告.md` 第3.1节。

### 3.2 业务层对底层模块的依赖

bladex-boot 业务层通过 Maven 依赖引入以下 Starter：

- `blade-core-boot` — Web 基础
- `blade-core-secure` — 安全认证
- `blade-core-oauth2` — OAuth2 认证
- `blade-starter-mybatis` — 数据访问
- `blade-starter-redis` — 缓存
- `blade-starter-tenant` — 多租户
- `blade-starter-tenant-dynamic` — 动态数据源
- `blade-starter-log` — 日志
- `blade-starter-swagger` — API 文档
- `blade-starter-flowable` — 工作流
- `blade-starter-excel` — Excel
- `blade-starter-oss` — 对象存储
- `blade-starter-sms` — 短信
- `blade-starter-powerjob` — 任务调度
- `blade-starter-data-scope` — 数据权限
- `blade-starter-data-record` — 数据审计
- `blade-starter-xss` — XSS 防护
- `blade-starter-api-crypto` — API 加解密

### 3.3 前端模块依赖

```
main.js (应用入口)
├── 依赖 Element Plus（UI 组件库）
├── 依赖 Avue（CRUD 框架）
├── 依赖 Vuex（状态管理）
│   ├── user 模块 → 依赖 api/user.js
│   ├── dict 模块 → 依赖 api/system/dict*.js
│   └── logs 模块 → 依赖 api/user.js (sendLogs)
├── 依赖 Vue Router（路由）
│   └── 动态路由 → 依赖 api/system/menu.js (getRoutes)
├── 依赖 axios.js（HTTP 客户端）
│   ├── 请求拦截 → 依赖 utils/crypto.js, utils/sm2.js, utils/auth.js
│   └── 响应拦截 → 依赖 store (Token 刷新)
└── 依赖 permission.js（路由守卫）
    └── 依赖 store (Token 校验)
```
