## 第1章：组件层级结构

### 1.1 组件树顶层

```
App.vue (根组件)
└── <router-view>
    ├── 静态路由页面 (PageRouter)
    │   ├── /login → page/login/index.vue
    │   │   ├── userLogin (用户名登录)
    │   │   ├── codeLogin (验证码登录)
    │   │   ├── thirdLogin (第三方登录)
    │   │   ├── registerLogin (注册登录)
    │   │   └── topLang (语言切换)
    │   ├── /lock → page/lock/index.vue (锁屏页)
    │   ├── /404 → components/error-page/404.vue
    │   ├── /403 → components/error-page/403.vue
    │   └── /500 → components/error-page/500.vue
    │
    ├── 主布局路由 (ViewsRouter)
    │   └── Layout (page/index/index.vue)
    │       ├── el-watermark (水印容器)
    │       ├── avue-sidebar (侧边栏)
    │       │   ├── logo (Logo组件)
    │       │   └── sidebar (菜单容器)
    │       │       └── sidebarItem (递归菜单项)
    │       └── avue-main (主内容区)
    │           ├── top (顶部导航栏)
    │           │   ├── top-lang (语言切换)
    │           │   └── 搜索、全屏、主题等功能
    │           ├── tags (标签页导航)
    │           ├── search (全局搜索)
    │           └── <router-view> (嵌套路由出口)
    │               └── keep-alive (缓存视图)
    │                   └── 业务页面 (views/)
    │
    └── 动态路由页面 (后端返回菜单 → formatRoutes 注册)
        └── Layout 或 直接页面组件
```

详见 `前端-分析报告.md` 第2.1节。

### 1.2 主布局组件

`page/index/index.vue`：
- 采用经典的左右布局：左侧 Sidebar + 右侧 Main
- 支持横向布局模式（`isHorizontal`）
- 包含：水印 → 侧边栏 → 顶部栏 → 标签页 → 搜索 → 内容区
- 通过 `validSidebar` computed 控制侧边栏显隐（路由 meta.menu 或 query.menu）

## 第3章：Vuex Store 模块详情

### 3.1 Store 模块概览

| 模块 | 路径 | 职责 | 持久化 |
|------|------|------|--------|
| user | `store/modules/user.js` | 用户认证、菜单、权限、角色 | localStorage: token, refreshToken, tenantId, userInfo, menu, menuAll; sessionStorage: permission |
| common | `store/modules/common.js` | 语言、侧边栏状态、全屏、锁屏、主题 | localStorage: language, colorName, themeName; sessionStorage: isLock, lockPasswd |
| tags | `store/modules/tags.js` | 标签页导航 | localStorage: tagList, tag |
| logs | `store/modules/logs.js` | 前端错误日志收集与上报 | localStorage: logsList |
| dict | `store/modules/dict.js` | 数据字典、流程路由配置 | localStorage: flowRoutes |

### 3.2 User 模块

**State**：

```javascript
{
  tenantId: '',        // 租户ID
  userInfo: {},        // 用户信息（userId, userName, deptId, roleId, roleName, avatar 等）
  permission: {},      // 按钮权限 { code: true }
  roles: [],           // 用户角色列表
  menuId: {},          // 当前选中菜单ID
  menu: [],            // 当前菜单树
  menuAll: [],         // 全部菜单树（累加模式）
  token: '',           // 访问令牌
  refreshToken: ''     // 刷新令牌
}
```

**Actions**：

| Action | 说明 | 调用 API |
|--------|------|---------|
| LoginByUsername | 用户名密码登录 | loginByUsername (SM2 加密密码) |
| LoginBySocial | 第三方社交登录 | loginBySocial |
| LoginBySso | 单点登录 | loginBySso |
| LoginByPhone | 手机验证码登录 | loginByPhone (SM2 加密手机号) |
| RegisterUser | 用户注册 | registerUser (SM2 加密密码) |
| GetUserInfo | 获取用户信息 | getUserInfo |
| RefreshToken | 刷新 Token | refreshToken |
| LogOut | 登出（调用后端） | logout |
| FedLogOut | 前端登出（不调用后端） | - |
| GetTopMenu | 获取顶级菜单 | getTopMenu |
| GetMenu | 获取菜单树 + 按钮权限 | getRoutes + getButtons |
| GetButtons | 获取按钮权限 | getButtons |

**关键变更链路**：

```
LoginByUsername → SET_TOKEN → setToken(Cookie) → localStorage
                → SET_REFRESH_TOKEN → setRefreshToken(Cookie) → localStorage
                → SET_TENANT_ID → localStorage
                → SET_USER_INFO → localStorage
                → DEL_ALL_TAG → 清空标签页
                → CLEAR_LOCK → 清除锁屏状态
```

### 3.3 Common 模块

**State**：

```javascript
{
  language: 'zh-cn',      // 当前语言
  isCollapse: false,      // 侧边栏折叠状态
  isFullScren: false,     // 全屏状态

  lockPasswd: '',         // 锁屏密码 (sessionStorage)

}
```

### 3.4 Tags 模块

**Mutations**：

| Mutation | 说明 |
|----------|------|
| ADD_TAG | 添加标签页（去重判断 fullPath），持久化 |
| DEL_TAG | 删除指定标签页 |
| DEL_ALL_TAG | 删除所有标签页（可保留部分） |
| DEL_TAG_OTHER | 仅保留当前 tag 和首页 tag |

### 3.5 持久化策略

| 存储类型 | Key 前缀 | 存储项 |
|---------|---------|--------|
| localStorage | `saber3-` | token, refreshToken, tenantId, userInfo, menu, menuAll, language, colorName, themeName, tagList, tag, logsList, flowRoutes |
| sessionStorage | `saber3-` | permission, isLock, lockPasswd |
| Cookie | `saber3-access-token` | Token |
| Cookie | `saber3-refresh-token` | RefreshToken |
| Cookie | `JSESSIONID` | 会话ID |
| Cookie | `b-user-id` | 用户ID |

Store 工具（`utils/store.js`）：
- `setStore({ name, content, type })`：`type` 为 'session' 存 sessionStorage，否则存 localStorage
- `getStore({ name, debug })`：先查 sessionStorage，再查 localStorage
- Key 自动添加前缀：`website.key + '-'` = `'saber3-'`

详见 `前端-分析报告.md` 第4.5节。

## 第4章：API 调用层封装

### 4.1 HTTP 客户端配置

**基础配置**（`axios.js`）：

```javascript
axios.defaults.timeout = 10000;                          // 10秒超时
axios.defaults.validateStatus = status => 200 <= status <= 500;  // 宽泛的状态码范围
axios.defaults.withCredentials = true;                   // 允许携带 Cookie
```

### 4.2 请求拦截器

| 步骤 | 处理内容 | 代码行 |
|------|---------|--------|
| 1 | 启动 NProgress 进度条 | L44 |
| 2 | URL 前缀补全：非绝对 URL 且非 baseUrl 开头则添加 baseUrl | L48-50 |
| 3 | 安全请求头：`Blade-Requested-With: BladeHttpRequest` | L52 |
| 4 | 语言请求头：`Accept-Language` | L54 |
| 5 | OAuth2 Basic 认证：`Authorization: Basic Base64(clientId:clientSecret)` | L56-61 |
| 6 | Token 注入：`Blade-Auth: bearer {token}` 或 `crypto {加密token}` | L63-74 |
| 7 | 报文加密：params/data 使用 AES-CBC 加密 | L76-85 |
| 8 | 表单序列化：POST + isSerialize → URLSearchParams 格式 | L91-93 |

**可配置项**（通过 config 属性控制）：
- `config.authorization = false`：不发送 Basic 认证头
- `config.meta.isToken = false`：不发送 Token
- `config.cryptoToken = true`：Token 使用 AES 加密
- `config.cryptoData = true`：请求/响应数据使用 AES 加密
- `config.meta.isSerialize = true`：POST 数据序列化为 form 格式

详见 `前端-分析报告.md` 第5.2节。

### 4.3 响应拦截器

| 状态码 | 处理逻辑 |
|--------|---------|
| 白名单状态码 | 直接 reject，由调用方处理 |
| 401 (首次) | 触发 Token 刷新，重试原请求 |
| 401 (已重试) | 清除 Token，跳转登录页 |
| >2000 (OAuth2 错误) | 显示 error_description，reject |
| !=200 (一般错误) | ElMessage 错误提示，reject |
| 200 | 正常返回响应 |
| 网络错误 | NProgress.done(), reject |

**Token 刷新机制**（FE-019）：

```
401 响应 → 检查 config._retry
├── 未重试过：
│   ├── 设置 _retry = true
│   ├── 检查 isRefreshing（是否已在刷新）
│   │   ├── 正在刷新：等待 refreshTokenPromise 完成，重发请求
│   │   └── 未刷新：开始刷新
│   │       ├── isRefreshing = true
│   │       ├── store.dispatch('RefreshToken')
│   │       │   ├── 成功：重置 isRefreshing，更新 Token，重发原请求
│   │       │   └── 失败：重置 isRefreshing，清除 Token，跳转登录
│   │       └── 返回 refreshTokenPromise
│   └── 已重试过：清除 Token，跳转登录
```

详见 `前端-分析报告.md` 第5.3节。
