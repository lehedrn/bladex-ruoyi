## 1. 实体模型总览

BladeX 的数据模型分为以下几类：
- **RBAC 核心模型**: User, Role, Menu, Dept
- **多租户模型**: Tenant, TenantPackage
- **权限模型**: DataScope, ApiScope, RoleMenu, RoleScope
- **字典与参数**: Dict, DictBiz, Param
- **辅助模型**: Post, UserDept, UserOauth, AuthClient, ApiKey

所有实体继承自 `org.springblade.core.mp.base.BaseEntity`，公共字段包括：
- `id` (BIGINT) — 雪花算法生成的主键
- `createUser` / `createDept` / `createTime` — 审计字段
- `updateUser` / `updateTime` — 更新审计
- `isDeleted` (TINYINT) — 逻辑删除标记
- `status` (INT) — 状态 (1=启用, 0=禁用)

## 2. RBAC 核心实体

### 2.1 User (用户)

**表名**: `blade_user`  
**实体类**: `org.springblade.modules.system.entity.User`

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| `id` | BIGINT | 主键 | PK, 雪花算法 |
| `tenant_id` | VARCHAR | 租户ID | 租户隔离 |
| `account` | VARCHAR | 登录账号 | UNIQUE(tenant_id, account) |
| `password` | VARCHAR | 密码 (BCrypt) | |
| `name` | VARCHAR | 昵称 | |
| `real_name` | VARCHAR | 真实姓名 | |
| `avatar` | VARCHAR | 头像URL | |
| `email` | VARCHAR | 邮箱 | |
| `phone` | VARCHAR | 手机号 | |
| `birthday` | DATE | 生日 | |
| `sex` | INT | 性别 (1=男, 2=女) | |
| `role_id` | VARCHAR | 角色ID列表 | 逗号分隔，如 "1,2,3" |
| `dept_id` | BIGINT | 部门ID | FK → blade_dept.id |
| `post_id` | BIGINT | 岗位ID | FK → blade_post.id |
| `leader_id` | BIGINT | 负责人ID | 仅领导岗位使用 |
| `is_leader` | INT | 是否负责人 | |

**业务规则**:
- 账号唯一性在租户级别 (`tenant_id + account`)
- `role_id` 使用逗号分隔字符串而非关联表，简化查询
- 支持逻辑删除 (`is_deleted`)

### 2.2 Role (角色)

**表名**: `blade_role`  
**实体类**: `org.springblade.modules.system.entity.Role`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `tenant_id` | VARCHAR | 租户ID |
| `parent_id` | BIGINT | 父角色ID (树结构) |
| `role_name` | VARCHAR | 角色名称 |
| `role_alias` | VARCHAR | 角色别名 (用于代码中引用) |
| `sort` | INT | 排序 |
| `status` | INT | 状态 |

**业务规则**:
- 支持树形结构（通过 `parent_id`）
- `role_alias` 用于 `@PreAuth("hasRole('admin')")` 等表达式
- 根角色 `parent_id = 0`

### 2.3 Menu (菜单)

**表名**: `blade_menu`  
**实体类**: `org.springblade.modules.system.entity.Menu`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `parent_id` | BIGINT | 父菜单ID |
| `code` | VARCHAR | 菜单编码 (唯一标识) |
| `name` | VARCHAR | 菜单名称 |
| `alias` | VARCHAR | 别名 |
| `path` | VARCHAR | 路由路径 |
| `source` | VARCHAR | 图标 |
| `component` | VARCHAR | Vue 组件路径 |
| `sort` | INT | 排序 |
| `category` | INT | **1=菜单, 2=按钮** |
| `action` | VARCHAR | 按钮权限标识 (如 "user:add") |
| `is_open` | INT | 是否新窗口打开 |

**业务规则**:
- **非租户隔离** — 所有租户共享同一菜单树
- `category=2` 的按钮用于 API 权限校验 (`hasPermission`)
- 前端路由通过 `category=1` 的菜单生成
- 树结构通过 `parent_id` 构建

### 2.4 Dept (部门)

**表名**: `blade_dept`  
**实体类**: `org.springblade.modules.system.entity.Dept`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `tenant_id` | VARCHAR | 租户ID |
| `parent_id` | BIGINT | 父部门ID |
| `full_name` | VARCHAR | 部门全称 |
| `dept_name` | VARCHAR | 部门名称 |
| `ancestors` | VARCHAR | 祖先路径 (逗号分隔) |
| `leader_id` | BIGINT | 负责人ID |
| `dept_category` | INT | 部门分类 |
| `sort` | INT | 排序 |

**业务规则**:
- `ancestors` 字段存储完整路径如 "1,2,3"，用于快速查询子部门
- 支持通过 `ancestors` 进行层级查询，避免递归

**实体类**: `org.springblade.modules.system.entity.Tenant`

| 字段 | 类型 | 说明 |

|------|------|------|

## 4. 权限实体

### 4.1 RoleMenu (角色-菜单关联)

**表名**: `blade_role_menu`  
**实体类**: `org.springblade.modules.system.entity.RoleMenu`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `role_id` | BIGINT | FK → blade_role.id |
| `menu_id` | BIGINT | FK → blade_menu.id |

### 4.2 RoleScope (角色-权限范围关联)

**表名**: `blade_role_scope`  
**实体类**: `org.springblade.modules.system.entity.RoleScope`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `role_id` | BIGINT | FK → blade_role.id |
| `scope_category` | INT | **1=数据权限, 2=API权限** |
| `scope_id` | BIGINT | FK → blade_scope_data.id 或 blade_scope_api.id |

### 4.3 DataScope (数据权限)

**表名**: `blade_scope_data`  
**实体类**: `org.springblade.modules.system.entity.DataScope`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `menu_id` | BIGINT | 关联菜单 (哪个功能页面的数据权限) |
| `resource_code` | VARCHAR | 资源编码 |
| `scope_name` | VARCHAR | 权限名称 |
| `scope_field` | VARCHAR | 字段名 (如 "dept_id") |
| `scope_class` | VARCHAR | 数据范围类 (自定义SQL实现) |
| `scope_column` | VARCHAR | 数据库列名 |
| `scope_type` | INT | **权限类型**: |
| | | 1=全部数据权限 |
| | | 2=自定义数据权限 |
| | | 3=本部门数据权限 |
| | | 4=本部门及以下数据权限 |
| | | 5=仅本人数据权限 |
| `scope_value` | VARCHAR | 权限值 (自定义模式下的部门ID列表) |

**业务规则**:
- `scope_type` 决定 SQL 生成逻辑
- `scope_type=2` 时，`scope_value` 为逗号分隔的部门ID
- 通过 `BladeScopeModelHandler` 在 MyBatis 层自动追加 WHERE 条件

## 5. 字典与参数

### 5.1 Dict (系统字典)

**表名**: `blade_dict`  
**实体类**: `org.springblade.modules.system.entity.Dict`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `parent_id` | BIGINT | 父字典ID (树结构) |
| `code` | VARCHAR | 字典编码 (如 "sex", "status") |
| `dict_key` | VARCHAR | 字典键 |
| `dict_value` | VARCHAR | 字典值 |
| `sort` | INT | 排序 |
| `is_sealed` | INT | 是否锁定 (内置字典不可删) |
| `status` | INT | 状态 |

**业务规则**:
- **非租户隔离** — 全局共享
- 树结构：父节点 `parent_id = 0`，子节点 `parent_id = 父节点id`

### 5.2 DictBiz (业务字典)

**表名**: `blade_dict_biz`

与 Dict 结构相同，但 **增加 `tenant_id` 字段实现租户隔离**。

### 5.3 Param (系统参数)

**表名**: `blade_param`  
**实体类**: `org.springblade.modules.system.entity.Param`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `tenant_id` | VARCHAR | 租户ID |
| `param_name` | VARCHAR | 参数名称 |
| `param_key` | VARCHAR | 参数键 |
| `param_value` | VARCHAR | 参数值 |

## 6. 辅助实体

### 6.1 UserDept (用户-部门关联)

**表名**: `blade_user_dept`

支持用户属于多个部门的多对多关系。

| 字段 | 类型 |
|------|------|
| `id` | BIGINT |
| `user_id` | BIGINT |
| `dept_id` | BIGINT |

### 6.2 UserOauth (第三方OAuth绑定)

**表名**: `blade_user_oauth`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `tenant_id` | VARCHAR | 租户ID |
| `uuid` | VARCHAR | 第三方平台用户ID |
| `user_id` | BIGINT | FK → blade_user.id |
| `username` | VARCHAR | 第三方平台用户名 |
| `nickname` | VARCHAR | 昵称 |
| `source` | VARCHAR | 来源 (github, gitee, wechat, qq, dingtalk) |

### 6.3 AuthClient (OAuth2 客户端)

**表名**: `blade_client`  
**实体类**: `org.springblade.modules.system.entity.AuthClient`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT | 主键 |
| `client_id` | VARCHAR | 客户端ID (如 "sword", "saber", "saber3") |
| `client_secret` | VARCHAR | 客户端密钥 |
| `scope` | VARCHAR | 授权范围 |
| `authorized_grant_types` | VARCHAR | 允许的授权类型 (逗号分隔) |
| `access_token_validity` | INT | access_token 有效期 (秒) |
| `refresh_token_validity` | INT | refresh_token 有效期 (秒) |

**已知客户端**:
- `sword` — 管理后台 (Vue 2)
- `saber` — 管理后台 (Vue 2 Element)
- `saber3` — 管理后台 (Vue 3)
- `rider` — APP/小程序端

## 7. 实体关系总结

```
blade_tenant (1) ──┬──< (N) blade_user
                    ├──< (N) blade_role
                    ├──< (N) blade_dept
                    ├──< (N) blade_dict_biz
                    ├──< (N) blade_param
                    ├──< (N) blade_post
                    └──(1) blade_tenant_package

blade_user (N) ──< (M) blade_role      [通过 role_id 逗号分隔]
blade_user (N) ──< (M) blade_dept      [通过 blade_user_dept]

blade_role (N) ──< (M) blade_menu      [通过 blade_role_menu]
blade_role (1) ──< (N) blade_role_scope

blade_menu ──tree──> blade_menu         [parent_id]
blade_role ──tree──> blade_role         [parent_id]
blade_dept ──tree──> blade_dept         [parent_id + ancestors]
blade_dict ──tree──> blade_dict         [parent_id]
```
