## 1. 核心术语表

### 1.1 架构相关

| 术语 | 英文 | 定义 | 代码位置 |
|------|------|------|----------|
| Starter | Starter | Spring Boot 自动配置模块，通过 `@AutoConfiguration` 实现按需装配 | blade-starter-* |
| Core 模块 | Core Module | 框架核心层，提供基础能力（启动、工具、数据库、安全等） | blade-core-* |
| 聚合模块 | Aggregator Module | 将多个 Core/Starter 组合在一起的入口模块，如 blade-core-boot | blade-core-boot/pom.xml |
| SPI 扩展 | SPI Extension | Service Provider Interface，通过 LauncherService 接口在启动阶段介入 | blade-core-launch/.../LauncherService.java |
| 自动配置 | AutoConfiguration | Spring Boot 3 的 `@AutoConfiguration` 注解，替代旧版 spring.factories | 各 starter 的 config 包 |
| BOM | Bill of Materials | 统一版本管理 POM，确保各模块依赖版本一致 | blade-bom/pom.xml |

## 2. 纠正对照表

| 易混淆说法 | 正确术语 | 说明 |
|-----------|---------|------|
| "登录接口" | `/blade-auth/oauth/token` | 不是独立的 API，而是 OAuth2 Token 端点 |
| "用户角色表" | `blade_user.role_id` (逗号分隔) | 不是独立的关联表，而是逗号分隔的 ID 字符串 |
| "菜单权限" | blade_menu.category | 1=菜单, 2=按钮。按钮级别的权限用于 hasPermission 校验 |
| "权限表" | 不存在统一的权限表 | 权限由 blade_menu(按钮) + blade_scope_data(数据) + blade_role_menu(角色-菜单) 共同构成 |
| "字典表" | blade_dict (系统) + blade_dict_biz (业务) | 系统字典不区分租户，业务字典租户隔离 |
| "部门树" | blade_dept.parent_id + ancestors | ancestors 字段存储完整路径，加速树查询 |
| "Spring Security" | 自定义安全框架 | BladeX 未使用 Spring Security，而是自研 SecureInterceptor + OAuth2 |

## 3. 命名规范

### 3.1 包命名

| 模式 | 示例 |
|------|------|
| 工具类 | `org.springblade.core.tool.utils.*` |
| 配置类 | `org.springblade.*.config.*` |
| 控制器 | `org.springblade.modules.*.controller.*` |
| 服务接口 | `org.springblade.modules.*.service.I*Service` |
| 服务实现 | `org.springblade.modules.*.service.impl.*ServiceImpl` |
| 实体类 | `org.springblade.modules.*.entity.*` |
| 包装对象 | `org.springblade.modules.*.wrapper.*Wrapper` |
| 视图对象 | `org.springblade.modules.*.vo.*VO` |

### 3.2 缓存 Key 规范

| 前缀 | 用途 | 示例 |
|------|------|------|
| `blade:auth::` | 认证相关缓存 | `blade:auth::user:123` |
| `blade:captcha:` | 验证码 | `blade:captcha:abc123` |
| `blade:lock::account:fail:` | 账户失败次数 | `blade:lock::account:fail:admin` |
| `blade:lock::ip:fail:` | IP 失败次数 | `blade:lock::ip:fail:192.168.1.1` |
| `SYS_CACHE` | 系统级缓存（菜单、权限等） | `SYS_CACHE:apiScope:code:user:list:1` |

### 3.3 API URL 规范

| 模块 | URL 前缀 |
|------|----------|
| 系统管理 | `/blade-system/` |
| 认证授权 | `/blade-auth/` |
| 资源管理 | `/blade-resource/` |
| 工作流 | `/blade-flow/` |

## 4. 隐式决策点

| 决策点 | 代码位置 | 说明 |
|--------|----------|------|
| 密码加密方式 | BladePasswordHandler | 生产环境使用 BCrypt，传输使用 SM2 加密 |
| 默认密码 | CommonConstant.DEFAULT_PASSWORD = "123456" | 新用户创建时的初始密码 |
| 树结构根节点 | TOP_PARENT_ID = 0L | 菜单、部门的根节点 parent_id |
| 租户授权模式 | tenant_id 字段 | 默认采用单库多租户（字段隔离），非独立数据库模式 |
| Token 有效期 | blade_client 表配置 | 各客户端（sword, saber, saber3）可配置不同的 token 有效期 |
