## 1. 密码与加密

### 1.1 密码存储

```
存储密码 = BCrypt.hash(明文密码)
```

- **代码来源**: `BladePasswordHandler.matches()` — bladex-boot
- **加密算法**: BCrypt (Spring Security 的 BCryptPasswordEncoder)
- **盐值**: 自动生成，嵌入哈希结果中

### 1.2 密码传输

```
传输密码 = SM2.encrypt(明文密码, 公钥)
```

- **代码来源**: 前端使用 SM2 公钥加密，后端使用 SM2 私钥解密
- **解密**: `BladeCryptoUtil.decrypt(password)` — 在 TokenGranter 中调用

### 1.3 弱密码校验

```
isWeakPassword(password) → password in ["123456", "admin123", "password", ...]
```

- **代码来源**: `BladeAuthorizationHandler.preValidation()`
- **仅生产环境生效**: 开发环境跳过

### 1.4 租户 License 解密

```
license = AES.decrypt(licenseKey, DES_KEY)
```

- **代码来源**: `TenantConstant.DES_KEY` — bladex-boot
- **用途**: 解密租户授权许可中的加密信息

## 2. 权限校验公式

### 2.1 API 权限校验

```
hasPermission(permissionCode) =
  EXISTS (
    SELECT 1 FROM blade_scope_data sd
    JOIN blade_role_scope rs ON rs.scope_id = sd.id
    WHERE rs.role_id IN (user.role_ids)
    AND rs.scope_category = 1  -- 数据权限
    AND sd.resource_code = permissionCode
  )
```

- **代码来源**: `BladePermissionHandler.hasPermission()`
- **缓存 Key**: `SYS_CACHE:apiScope:code:{permissionCode}:{roleId}`

### 2.2 菜单权限校验

```
hasMenu(menuCode) =
  EXISTS (
    SELECT 1 FROM blade_menu m
    JOIN blade_role_menu rm ON rm.menu_id = m.id
    WHERE rm.role_id IN (user.role_ids)
    AND m.code = menuCode
  )
```

- **代码来源**: `BladePermissionHandler.hasMenu()`
- **缓存 Key**: `SYS_CACHE:apiScope:menu:{menuCode}:{roleId}`
- **递归逻辑**: 查询到子菜单后，需要递归获取所有父级菜单

### 2.3 全路径权限校验

```
permissionAll(requestURI) =
  EXISTS path IN user.paths WHERE requestURI LIKE path + "%"
```

- **代码来源**: `BladePermissionHandler.permissionAll()`
- **用途**: 检查用户是否有某个 URI 前缀的访问权限

### 2.4 数据权限 SQL 生成

根据 `scope_type` 生成不同的 WHERE 条件：

| scope_type | SQL 追加条件 |
|-----------|-------------|
| 1 (全部) | `-- 不追加条件` |
| 2 (自定义) | `AND {scope_column} IN ({scope_value})` |
| 3 (本部门) | `AND {scope_column} = {current_user.dept_id}` |
| 4 (本部门及以下) | `AND {scope_column} IN ({ancestors}, {current_user.dept_id})` |
| 5 (仅本人) | `AND {scope_column} = {current_user.user_id}` 或 `AND create_user = {user_id}` |

- **代码来源**: `BladeScopeModelHandler`
- **触发点**: MyBatis 拦截器，在 SQL 执行前追加条件

## 3. 租户校验公式

### 3.1 租户状态验证

```
isTenantValid(tenantId) =
  tenant EXISTS
  AND tenant.status = 1 (启用)
  AND (tenant.expire_time IS NULL OR tenant.expire_time > NOW())
```

- **代码来源**: `BladeAuthorizationHandler.authValidation()`
- **触发点**: 每次 Token 生成时（登录 + 刷新）

### 3.2 租户套餐权限

```
tenantAvailableMenus = tenant_package.menu_id.split(",")
```

- **代码来源**: 租户创建时从 `TenantPackage` 读取菜单列表
- **用途**: 限制租户可用的菜单范围

## 5. 账户锁定公式

### 5.1 失败计数

```
accountFailCount = Redis.GET("blade:lock::account:fail:" + account)
ipFailCount = Redis.GET("blade:lock::ip:fail:" + ip)
```

- **代码来源**: `BladeLockHandler`
- **锁定阈值**: 配置决定（通常 5 次）
- **锁定时间**: 配置决定（通常 30 分钟）

### 5.2 锁定逻辑

```
if (failCount >= threshold) {
  锁定时间 = Redis.TTL(lockKey)
  if (锁定时间 > 0) {
    抛出 AccountLockedException
  } else {
    重置计数 = Redis.DEL(lockKey)
  }
}
```

## 6. 部门树查询公式

### 6.1 子部门查询

```
getChildDeptIds(parentDeptId) =
  SELECT id FROM blade_dept WHERE ancestors LIKE "{parentDeptId}%"
```

- 利用 `ancestors` 字段避免递归查询
- **代码来源**: `DeptServiceImpl` / `SysCache`

### 6.2 部门路径查询

```
getDeptPath(deptId) =
  SELECT full_name FROM blade_dept
  WHERE id IN (ancestors.split(",") + deptId)
  ORDER BY FIND_IN_SET(id, ancestors + "," + deptId)
```

## 8. 隐式业务规则

### 8.1 用户创建流程隐式规则

```
submit(User user):
  1. 若 user.id == null → 新增
     - 自动加密密码 (BCrypt)
     - 设置默认密码 (如无)
     - 设置 is_deleted = 0
  2. 若 user.id != null → 更新
     - 不修改密码 (除非显式调用 resetPassword)
     - 保留原有 role_id (除非显式传入)
```

### 8.2 菜单路由生成

```
前端路由 = SELECT * FROM blade_menu
           WHERE category = 1 (菜单)
           AND status = 1
           AND id IN (
             SELECT menu_id FROM blade_role_menu
             WHERE role_id IN (user.role_ids)
           )
           ORDER BY sort
```

- **代码来源**: `MenuController.routes()`
- **用途**: 前端动态路由生成

### 8.3 数据权限与租户隔离叠加

```
最终 SQL WHERE 条件 =
  租户条件: tenant_id = {BladeContext.tenantId}
  + 数据权限条件: {scope_column} IN/=/... (根据 scope_type)
```

- 两个条件通过 AND 连接
- **代码来源**: `BladeScopeModelHandler` + 租户 MyBatis 拦截器
