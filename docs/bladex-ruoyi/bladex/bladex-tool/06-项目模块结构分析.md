## 2. bladex-tool 模块分析

### 2.1 功能分层

| 层级 | 模块组 | 模块数量 | 职责 |
|------|--------|---------|------|
| **L0 注解处理** | blade-core-auto | 1 | 编译期注解处理 |
| **L1 基础设施** | launch | 1 | 启动配置、Undertow、SPI |
| **L2 工具集** | tool | 1 | 通用工具、Jackson、加密 |
| **L3 数据上下文** | context, db | 2 | 请求上下文、数据库基础 |
| **L4 服务治理** | cloud, secure, oauth2 | 3 | 微服务、安全、OAuth2 |
| **L5 聚合** | boot | 1 | 一键引入所有核心能力 |
| **认证子模块** | jwt, key, auth, social, secure, oauth2 | 6 | 认证授权 |
| **数据 Starter** | redis, cache, mybatis, db-dynamic, sharding, mongo, ehcache, encrypt | 8 | 数据访问 |
| **业务 Starter** | tenant, tenant-dynamic, data-scope, data-record, oss, sms, excel | 7 | 业务能力 |
| **集成 Starter** | flowable, liteflow, literule, powerjob | 4 | 中间件集成 |
| **运维 Starter** | log, swagger, xss, prometheus, metrics, trace, actuate | 7 | 可观测性 |
| **辅助 Starter** | http, i18n, holidays, report, develop, loadbalancer, transaction, api-crypto | 8 | 辅助功能 |

### 2.2 各模块职责说明

#### Core 模块

| 模块 | 包路径 | 核心类 | 职责 |
|------|--------|--------|------|
| blade-core-auto | org.springblade.core.auto | 无 | 注解处理器，处理自动配置注册 |
| blade-core-launch | org.springblade.core.launch | BladeApplication, LauncherService | 启动入口、SPI 扩展、Undertow 配置 |
| blade-core-tool | org.springblade.core.tool | BladeUtil, JacksonUtil, SecureUtil | 工具类、JSON 序列化、加密 |
| blade-core-context | org.springblade.core.context | BladeContext | 请求上下文(ThreadLocal) |
| blade-core-db | org.springblade.core.db | MybatisPlusAutoConfiguration | MyBatis-Plus + Druid 基础配置 |
| blade-core-cloud | org.springblade.core.cloud | SentinelConfig, FeignConfig | Sentinel、Feign、Admin 集成 |
| blade-core-boot | org.springblade.core.boot | BladeBootAutoConfiguration | 聚合自动配置 |
| blade-core-secure | org.springblade.core.secure | SecureInterceptor | 安全拦截 |
| blade-core-oauth2 | org.springblade.core.oauth2 | OAuth2 相关配置 | OAuth2 服务 |

#### Starter 模块（重点）

| 模块 | 核心功能 | 关键类 |
|------|----------|--------|
| blade-starter-redis | Redis 连接 + Redisson 分布式锁 | RedissonConfiguration |
| blade-starter-mybatis | MyBatis-Plus 分页、乐观锁、逻辑删除 | MybatisPlusConfiguration |
| blade-starter-tenant | 多租户隔离 (tenant_id 字段) | TenantAutoConfiguration |
| blade-starter-swagger | Knife4j API 文档 | SwaggerAutoConfiguration |
| blade-starter-log | AOP 操作日志记录 | LogAutoConfiguration |
| blade-starter-xss | XSS 过滤 | XssAutoConfiguration |
| blade-starter-flowable | Flowable 工作流 | FlowableConfiguration |
| blade-starter-oss | 6 种对象存储统一接口 | OssTemplate |
| blade-starter-sms | 4 种短信平台统一接口 | SmsTemplate |
| blade-starter-powerjob | PowerJob 分布式任务 | PowerJobConfiguration |

## 3. bladex-boot 业务模块分析

### 3.1 common 通用包

| 子包 | 职责 | 关键类 |
|------|------|--------|
| cache/ | 缓存封装 (Redis + 本地) | SysCache, UserCache, DictCache, DictBizCache, ParamCache |
| config/ | Spring 配置类 | BladeConfiguration, SwaggerConfiguration, BladeHandlerConfiguration |
| constant/ | 常量接口 | CommonConstant, DictConstant, TenantConstant, LauncherConstant |
| enums/ | 枚举定义 | DictEnum, DictBizEnum |
| event/ | Spring 事件监听 | ApiLogListener, ErrorLogListener |
| handler/ | 业务处理器 | BladePermissionHandler, BladeRecordHandler, BladeScopeModelHandler |
| launch/ | 启动时服务 | LauncherServiceImpl |
| utils/ | 业务工具类 | 各种工具方法 |

### 3.2 modules 业务包

| 模块 | Controller 数 | 核心功能 | URL 前缀 |
|------|--------------|----------|----------|
| auth | 1 | OAuth2 认证、Token 管理 | /blade-auth/ |
| system | 22 | 用户、角色、菜单、部门、字典、租户等 | /blade-system/ |
| resource | 3 | OSS、SMS、附件管理 | /blade-resource/ |
| desk | 1 | 公告管理 | /blade-desk/ |
| develop | 2 | 代码生成、模型管理 | /blade-develop/ |

### 3.3 system 模块详解

**Controller 分组**:

| 分组 | Controller | 职责 |
|------|-----------|------|
| **用户管理** | UserController | CRUD、密码重置、角色分配、导入导出 |
| **组织架构** | RoleController, DeptController, PostController | 角色树、部门树、岗位 |
| **菜单管理** | MenuController | 菜单树、前端路由、按钮权限 |
| **字典管理** | DictController, DictBizController | 系统字典、业务字典 |
| **租户管理** | TenantController, TenantPackageController | 租户 CRUD、套餐管理 |
| **权限管理** | DataScopeController, ApiScopeController | 数据权限、API 权限 |
| **系统参数** | ParamController | 键值对配置 |
| **OAuth2 客户端** | AuthClientController | 客户端管理 |
| **日志管理** | LogApiController, LogErrorController, LogUsualController | API 日志、错误日志、普通日志 |
| **其他** | RegionController, TopMenuController, SearchController, ApiKeyController, RecordDataController | 行政区划、顶部菜单、搜索、API Key、审计记录 |

### 3.4 resource 模块

| Controller | 职责 |
|-----------|------|
| OssController | 对象存储配置与文件上传 |
| SmsController | 短信配置与发送 |
| AttachController | 附件管理 (上传记录) |

### 3.5 develop 模块

| Controller | 职责 |
|-----------|------|
| CodeController | 代码生成器 (基于模板) |
| ModelController | 数据模型定义 (用于代码生成) |

## 4. 配置文件分层

```
resources/
├── application.yml              # 全局基础配置
│   ├── spring.profiles.active   # 环境切换
│   ├── blade 配置               # 框架自定义配置
│   └── mybatis-plus 配置        # ORM 配置
├── application-dev.yml          # 开发环境 (本地数据库)
├── application-test.yml         # 测试环境
├── application-prod.yml         # 生产环境
├── blade-boot.yml               # 自定义启动配置 (通过 @BladePropertySource 加载)
├── processes/                   # Flowable BPMN 流程定义
│   └── LeaveProcess.bpmn20.xml  # 请假流程示例
├── mapper/                      # MyBatis SQL 映射
│   ├── system/                  # 系统模块 XML
│   ├── auth/                    # 认证模块 XML
│   └── ...
└── i18n/                        # 国际化资源
    └── messages.properties
```
