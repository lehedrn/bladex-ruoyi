## 第1章：核心实体类详解

### 1.1 实体继承体系

```
Serializable（Java 基础接口）
  ├── BaseEntity（bladex-tool 提供）
  │     字段：id, createUser, createTime, updateUser, updateTime
  │     └── TenantEntity
  │           字段：tenantId, isDeleted
  │           ├── User
  │           ├── Tenant
  │           └── 其他租户相关实体
  │
  ├── Role（直接实现 Serializable）
  │     字段：tenantId, parentId, roleName, roleAlias, sort, status
  │
  ├── Menu（直接实现 Serializable）
  │     字段：parentId, code, name, category, path, sort, isDeleted
  │
  └── Dept（直接实现 Serializable）
        字段：tenantId, parentId, fullName, deptName, ancestors, leaderId, deptCategory
```

详见 `后端-分析报告.md` 第3.2节。

### 1.2 User（用户实体）

| 维度 | 值 |
|------|------|
| 表名 | `blade_user` |
| 继承 | `TenantEntity` |
| 主键策略 | `@TableId(type = IdType.ASSIGN_ID)` 雪花算法 |
| 逻辑删除 | `@TableLogic` 标注 `isDeleted` 字段 |

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| account | String | 登录账号，租户内唯一（BE-002） |
| password | String | BCrypt 加密存储（BE-001） |
| realName | String | 真实姓名 |
| phone | String | 手机号，租户内唯一（BE-003），前端 SM2 加密传输 |
| email | String | 邮箱 |
| roleId | String | 角色ID，逗号分隔多值（FE-034） |
| deptId | String | 部门ID，逗号分隔多值 |
| postId | String | 岗位ID，逗号分隔多值 |
| leaderId | String | 主管ID，逗号分隔多值 |
| isLeader | Integer | 是否主管（0/1） |
| tenantId | String | 租户ID（继承 TenantEntity） |
| userType | Integer | 平台类型（WEB/APP/OTHER） |
| status | Integer | 状态（正常/锁定等） |

**业务规则**：
- 用户不可删除自身（BE-006）
- 修改自身信息时忽略角色/部门/岗位/账号/主管字段（BE-008）
- 审核通过前需已分配角色、部门、岗位（BE-009）
- 新注册用户默认未激活（BE-010），分配 guest 角色（BE-011）
- 支持多对多部门关联（BE-044），通过 `blade_user_dept` 中间表

### 1.3 Role（角色实体）

| 维度 | 值 |
|------|------|
| 表名 | `blade_role` |
| 继承 | `Serializable` |

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantId | String | 租户ID |
| parentId | Long | 父角色ID（支持角色树） |
| roleName | String | 角色名称 |
| roleAlias | String | 角色别名（排除 ADMINISTRATOR，BE-018） |
| sort | Integer | 排序 |
| status | Integer | 状态 |

**业务规则**：
- 非超管不可配置超管角色（BE-013）/管理员角色（BE-014）
- 授予权限时递归清理子角色的无权菜单（BE-015）
- 不可创建超管角色（BE-016）
- 不可删除有子节点的角色（BE-017）

### 1.4 Menu（菜单实体）

| 维度 | 值 |
|------|------|
| 表名 | `blade_menu` |
| 继承 | `Serializable` |

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| parentId | Long | 父菜单ID |
| code | String | 菜单编号，全局唯一（BE-021） |
| name | String | 菜单名称，全局唯一 |
| category | Integer | 类型：1=菜单，2=按钮 |
| path | String | 路由路径，全局唯一 |
| sort | Integer | 排序 |
| icon | String | 图标 |
| isOpen | Integer | 是否缓存（1=不缓存，2=缓存） |
| isDeleted | Integer | 逻辑删除标记 |

**业务规则**：
- code/name/path 全局唯一（BE-021）
- 父节点必须为菜单类型（BE-022）
- 不可删除有子节点的记录（BE-023）
- 超级管理员可访问全部菜单（BE-019）
- 普通用户菜单通过租户产品包过滤（BE-020）

### 1.5 Dept（部门实体）

| 维度 | 值 |
|------|------|
| 表名 | `blade_dept` |
| 继承 | `Serializable` |

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantId | String | 租户ID |
| parentId | Long | 父部门ID |
| fullName | String | 部门全称 |
| deptName | String | 部门名称 |
| ancestors | String | 祖先路径（自动维护，BE-026） |
| leaderId | String | 主管ID |
| deptCategory | Integer | 部门类型 |

**业务规则**：
- 非超管只可查看本级及以下部门数据（BE-024）
- 不可删除有子节点的记录（BE-025）
- 创建时自动维护 ancestors（BE-026）
- 不可选择自身作为父节点（BE-027）

### 1.6 Tenant（租户实体）

| 维度 | 值 |
|------|------|
| 表名 | `blade_tenant` |
| 继承 | `TenantEntity` |

**关键字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| tenantId | String | 租户ID |
| tenantName | String | 租户名称 |
| contactNumber | String | 联系电话 |
| domainUrl | String | 域名（需唯一） |
| packageId | Long | 产品包ID |
| accountNumber | Integer | 账号额度 |
| expireTime | Date | 过期时间 |

**业务规则**：
- 租户编码唯一性校验
- 域名唯一性校验
- 三阶段删除：recycle → pass → remove（BE-046）
- 操作后清除 SYS_CACHE（BE-028）

## 第4章：VO 对象与 Wrapper 转换

| VO 类 | 来源实体 | 用途 |
|-------|---------|------|
| UserVO | User | 用户列表/详情展示，含字典翻译 |
| RoleVO | Role | 角色树形展示 |
| MenuVO | Menu | 菜单树形/路由展示 |
| DeptVO | Dept | 部门树形展示 |
| TenantVO | Tenant | 租户查询条件封装 |
| DictVO / DictBizVO | Dict / DictBiz | 字典树形展示 |
| PostVO | Post | 岗位分页展示 |
| DataScopeVO | DataScope | 数据权限展示 |
| ApiScopeVO | ApiScope | 接口权限展示 |
| OssVO | Oss | OSS 配置展示 |
| AttachVO | Attach | 附件展示 |
| SmsVO | Sms | 短信配置展示 |
| JobInfoVO | JobInfo | 任务信息展示 |
| RegionVO | Region | 行政区划展示 |

### 4.2 Wrapper 转换模式

详见 `后端-分析报告.md` 第3.3节。

```
Wrapper 转换模式：
Entity → XxxWrapper.build().entityVO(entity) → VO
Entity List → XxxWrapper.build().listVO(list) → VO List
Entity List → XxxWrapper.build().listNodeVO(list) → VO 树形列表
Entity List → XxxWrapper.build().listNodeLazyVO(list) → VO 懒加载树形
IPage<Entity> → XxxWrapper.build().pageVO(pages) → IPage<VO>
```

Wrapper 类继承自 `BaseWrapper`（bladex-tool 提供）。

## 第5章：数据库表关系

详见 `后端-分析报告.md` 第3.4节。

```
blade_tenant (1) ←→ (N) blade_user (通过 tenantId)
blade_tenant (1) ←→ (1) blade_tenant_package (通过 packageId)

blade_user (N) ←→ (N) blade_dept (通过 blade_user_dept 中间表)
blade_user (N) ←→ (N) blade_role (通过 user.roleId 逗号分隔存储)

blade_role (N) ←→ (N) blade_menu (通过 blade_role_menu 中间表)
blade_role (N) ←→ (N) blade_data_scope (通过 blade_role_scope, scopeCategory=1)
blade_role (N) ←→ (N) blade_api_scope (通过 blade_role_scope, scopeCategory=2)

blade_dept (N) ←→ (1) blade_dept (父子关系，通过 parentId/ancestors)
blade_role (N) ←→ (1) blade_role (父子关系，通过 parentId)
blade_menu (N) ←→ (1) blade_menu (父子关系，通过 parentId)
blade_dict (N) ←→ (1) blade_dict (父子关系，通过 parentId)

blade_user (1) ←→ (N) blade_user_web/app/other (通过 userId, 按平台分表)
blade_user (1) ←→ (N) blade_user_oauth (通过 userId)

blade_top_menu (N) ←→ (N) blade_menu (通过 blade_top_menu_setting 中间表)
```

### 5.1 软删除

使用 `@TableLogic` 注解标注 `isDeleted` 字段：
- `0` = 未删除（`BladeConstant.DB_NOT_DELETED`）
- `1` = 已删除

租户模块使用"回收站"模式（先标记回收，再彻底删除）（BE-046）。

## 第6章：MyBatis XML 映射要点

### 6.1 分页实现

使用 MyBatis-Plus 分页插件，通过 `Condition.getPage(Query)` 获取分页对象。

详见 `后端-分析报告.md` 第2.3节。

### 6.2 自定义 SQL（XML 映射）

每个 Mapper 都有对应的 XML 文件（与 Java 接口同目录），主要包含：

| SQL 类型 | 说明 |
|---------|------|
| 树形结构查询 | tree/lazyTree 查询，递归获取子节点 |
| 角色菜单关联查询 | 通过 blade_role_menu 关联查询 |
| 多表联合查询 | 用户-部门-角色联合查询 |
| 数据导出查询 | Excel 导出专用 SQL |

### 6.3 MyBatis 拦截器链顺序

详见 `底层架构-分析报告.md` AR-013。

```
TenantLineInnerInterceptor（可选，租户过滤）
  → DataChangeRecorderInnerInterceptor（可选，数据审计）
    → PaginationInnerInterceptor（分页）
```
