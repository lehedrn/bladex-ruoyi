# 03-数据模型使用手册

> 分析日期: 2026-05-21
> 涉及源文件: `sources/bladex/bladex-boot/src/main/java/org/springblade/modules/system/pojo/entity/` 下全部 20 个实体类
> 核心结论: BladeX 共 34 张表, 无外键约束, 无二级索引, 统一使用雪花算法 bigint 主键, is_deleted 逻辑删除, tenant_id 租户隔离。

## 1. 数据库概况

| 项目 | 值 |
|------|------|
| 数据库版本 | MySQL 8.3 |
| 表数量 | 34 张 |
| 外键约束 | 无 |
| 二级索引 | 无 |
| 逻辑删除 | is_deleted (0=正常, 1=删除), 通过 MyBatis-Plus @TableLogic 实现 |
| 主键策略 | bigint 雪花算法 (MyBatis-Plus IdType.ASSIGN_ID) |
| 租户字段 | tenant_id varchar(12), 默认值 '000000' |
| 租户过滤排除 | blade_user 被排除在租户自动过滤之外 |

## 12. 实体关系总结

### 12.1 一对多关系 (1:N)

| 父表 | 子表 | 关系字段 | 说明 |
|------|------|----------|------|
| blade_role | blade_role (自引用) | parentId | 角色树形层级 |
| blade_menu | blade_menu (自引用) | parentId | 菜单树形层级 |
| blade_dept | blade_dept (自引用) | parentId | 部门树形层级 |
| blade_dict | blade_dict (自引用) | parentId | 系统字典树形层级 |
| blade_dict_biz | blade_dict_biz (自引用) | parentId | 业务字典树形层级 |
| blade_tenant_package | blade_tenant | packageId | 产品包 -> 租户 |
| blade_tenant_datasource | blade_tenant | datasourceId | 数据源 -> 租户 |
| blade_datasource | blade_model | datasourceId | 数据源 -> 数据模型 |
| blade_model | blade_model_prototype | modelId | 数据模型 -> 数据原型 (1:N) |
| blade_model | blade_code | modelId | 数据模型 -> 代码生成配置 |
| blade_top_menu | blade_top_menu_setting | topMenuId | 顶部菜单 -> 菜单设置 (1:N) |

### 12.2 多对多关系 (N:M)

| 表 A | 关联表 | 表 B | 说明 |
|------|--------|------|------|
| blade_role | blade_role_menu | blade_menu | 角色-菜单权限 |
| blade_role | blade_role_scope | blade_scope_data | 角色-数据权限 |
| blade_role | blade_role_scope | blade_scope_api | 角色-API权限 |
| blade_user | blade_user_dept | blade_dept | 用户-部门 |
| blade_top_menu | blade_top_menu_setting | blade_menu | 顶部菜单-子菜单 |

### 12.3 一对多关系 (用户关联)

| 表 A | 关联方式 | 表 B | 说明 |
|------|----------|------|------|
| blade_user | roleId (逗号分隔) | blade_role | 用户可拥有多个角色 |
| blade_user | deptId (逗号分隔) | blade_dept | 用户可属于多个部门 |
| blade_user | postId | blade_post | 用户关联岗位 |
| blade_user | leaderId | blade_user | 用户主管关联 |

### 12.4 第三方认证关联

| 表 A | 关联字段 | 表 B | 说明 |
|------|----------|------|------|
| blade_user_oauth | userId | blade_user.id | 第三方账号关联系统用户 |
| blade_user_oauth | uuid + source | (外部第三方系统) | 唯一标识第三方用户 |

### 12.5 树形结构自引用

以下表通过 parentId 实现自引用树形结构:

- blade_role (角色树)
- blade_menu (菜单树, 无租户)
- blade_dept (部门树)
- blade_dict (系统字典树)
- blade_dict_biz (业务字典树)
- blade_region (行政区划树, 使用 parentCode)
