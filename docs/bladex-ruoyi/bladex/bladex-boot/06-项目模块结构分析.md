# 06-项目模块结构分析

> 分析日期: 2026/05/20
> 源文件路径: sources/bladex/bladex-boot/
> 核心结论: BladeX-Boot 采用典型的单体模块化架构，以 common 为基础支撑、system 为核心业务、resource 为外部资源集成、auth 为安全认证、desk/develop 为扩展功能。模块职责清晰，通过 BladeX Starter 体系实现高内聚低耦合。

## 1. 项目整体目录结构

```
sources/bladex/bladex-boot/
├── pom.xml                     # Maven 构建配置
├── src/main/java/org/springblade/
│   ├── Application.java        # 启动类 (@EnableScheduling + @EnableRedisHttpSession + @SpringBootApplication)
│   ├── common/                 # 通用模块 (28 Java 文件)
│   │   ├── cache/ (7)          # SysCache, UserCache, DictCache, DictBizCache, ParamCache, RegionCache, CacheNames
│   │   ├── config/ (5)         # BladeConfiguration, BladeHandlerConfiguration, BladeLogConfiguration, BladeReportConfiguration, SwaggerConfiguration
│   │   ├── constant/ (4)       # CommonConstant, DictConstant, TenantConstant, LauncherConstant
│   │   ├── enums/ (2)          # DictEnum, DictBizEnum
│   │   ├── event/ (3)          # ApiLogListener, ErrorLogListener, UsualLogListener
│   │   ├── handler/ (3)        # BladePermissionHandler, BladeRecordHandler, BladeScopeModelHandler
│   │   ├── launch/ (1)         # LauncherServiceImpl
│   │   ├── preview/ (3)        # BladePreviewConfiguration, BladePreviewFilter, BladePreviewProperties
│   │   └── utils/ (1)          # CommonUtil
│   └── modules/
│       ├── auth/ (15)          # OAuth2 认证模块
│       ├── system/ (170+)      # 系统管理核心模块
│       ├── resource/ (54)      # 资源管理 (OSS/SMS/附件)
│       ├── desk/ (7)           # 仪表盘 (公告)
│       └── develop/ (28)       # 代码生成器
├── src/main/resources/
│   ├── application.yml         # 全局基础配置
│   ├── application-dev.yml     # 开发环境
│   ├── application-test.yml    # 测试环境
│   ├── application-prod.yml    # 生产环境
│   ├── mapper/                 # MyBatis XML Mapper 文件
│   ├── processes/              # BPMN 流程定义文件
│   └── i18n/                   # 国际化资源文件
└── doc/
    ├── sql/                    # 数据库脚本 (MySQL/PG/Oracle/SQLServer/达梦/金仓)
    └── script/                 # Docker 部署脚本
```

### 目录结构特征

| 层级 | 路径 | 职责 |
|------|------|------|
| 根包 | `org.springblade` | 统一命名空间，与 BladeX 框架保持一致 |
| common | `org.springblade.common` | 跨模块共享能力：缓存、配置、常量、事件、Handler |
| modules | `org.springblade.modules` | 业务功能模块，按领域拆分为 auth/system/resource/desk/develop |
| resources | `src/main/resources` | 配置分层 + MyBatis XML + 流程定义 + 国际化 |
| doc | `doc/` | 数据库初始化脚本 + 部署脚本，支持多数据库 |

## 4. 启动类分析

### 4.1 Application.java

```
位置: src/main/java/org/springblade/Application.java
```

**注解组合：**

| 注解 | 作用 |
|------|------|
| `@EnableScheduling` | 启用 Spring 定时任务调度 |
| `@EnableRedisHttpSession` | 启用基于 Redis 的分布式 Session |
| `@SpringBootApplication` | Spring Boot 核心注解（自动配置 + 组件扫描） |

**启动方式：**

```java
BladeApplication.run(CommonConstant.APPLICATION_NAME, Application.class, args)
```

使用 BladeX 自定义的 `BladeApplication.run()` 替代原生 `SpringApplication.run()`，内置 BladeX 框架的初始化逻辑（Banner、环境准备、启动器回调等）。

### 6.2 仅 ResultMap 的 Mapper

以下 Mapper XML 仅包含 `<resultMap>` 定义，无自定义 SQL（查询通过 MyBatis-Plus Wrapper 完成）：

- `DataScopeMapper`
- `UserDeptMapper`
- `UserOauthMapper`
- 以及其他 20+ 个 Mapper

### 6.3 SQL 特征总结

| 特征 | 说明 |
|------|------|
| 树形查询 | 大量使用递归 CTE 或自连接实现树形结构（菜单、部门、字典） |
| 分页查询 | 配合 MyBatis-Plus 分页插件，XML 中仅写基础查询语句 |
| 条件组装 | 通过 `<if>`/`<where>`/`<foreach>` 实现动态 SQL |
| 批量操作 | `getDeptNames`/`getRoleNames` 等用于批量获取名称，减少 N+1 查询 |

### 8.2 依赖层级说明

| 层级 | 组件 | 说明 |
|------|------|------|
| L0 - 基础层 | `blade-core-auto` | 自动配置基座，提供条件装配、Bean 注册等底层能力 |
| L1 - 启动层 | `blade-core-launch` | 启动器框架，定义启动前/后生命周期钩子 |
| L2 - 工具层 | `blade-core-tool` | 工具类集合（工具方法、异常处理、响应封装等） |
| L3 - 核心层 | `blade-core-boot` | 核心启动器，自动装配所有 Starter，排除 Cloud 组件 |
| L3 - 认证层 | `blade-core-oauth2` | OAuth2 安全认证，与 boot 并列 |
| L4 - 功能层 | 所有 `blade-starter-*` | 按需启用的功能模块，通过 Starter 自动装配 |
| L5 - 应用层 | `BladeX-Boot` | 本项目，编写业务代码，依赖 L3/L4 |

- **auth → common**：认证过程依赖 `UserCache`、`SysCache` 获取用户信息
- **system → common**：系统管理依赖所有 Cache/Handler/Constant
- **resource → common**：资源管理依赖配置和缓存
- **desk → common**：公告依赖 `@DataRecord` → `BladeRecordHandler`
- **develop → common**：代码生成依赖配置

### 8.4 关键设计模式总结

| 模式 | 应用位置 | 说明 |
|------|----------|------|
| Starter 自动装配 | 所有 `blade-starter-*` | 通过 Spring Boot `@EnableAutoConfiguration` 实现按需加载 |
| Builder 规则链 | resource 模块 (OssBuilder/SmsBuilder) | 配置驱动的多后端适配 |
| 事件监听 | event/ (3 个 Listener) | 异步日志记录，解耦业务与审计 |
| Handler 扩展 | handler/ (3 个 Handler) | 权限/数据范围/审计的可插拔处理 |
| Cache 封装 | cache/ (6 个 Cache 类) | 统一缓存前缀管理，避免 key 冲突 |
| 分层配置 | application*.yml | 全局默认 + 环境覆盖 |
